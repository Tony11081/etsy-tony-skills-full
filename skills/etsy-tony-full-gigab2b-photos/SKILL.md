# Etsy-Tony：GigaB2B 图片生产

根据指定商品 URL、SKU 或已授权的收藏清单完成素材提取、完整摄影计划、实际生成、视觉验收与文件交付。默认 15 张独立图片；用户指定数量时按请求执行，没有每次 3 张的限制。

## 依赖与范围

- 浏览器优先使用宿主可用的内置浏览器，其次使用已登录 Chrome；读取所用工具说明，只使用已提供的接口。
- 生成阶段读取 [完整摄影引擎](../etsy-tony-full-photo-engine/SKILL.md)。本包已经包含实现，不依赖作者本机私有插件。
- 最终图片使用 Codex 内置 `image_gen`。宿主没有此能力时准确说明阻塞；用户指定其他可用引擎时再按其约束适配。不要把提示词当成图片。
- 不下采购单、不加入购物车、不修改收藏或账号设置。提取请求只做提取；已经要求出图时接着完成出图，无需重新调用。

## 1. 识别商品与恢复任务

读取指定页的主标题、主商品 Item Code、URL 和 product_id。忽略推荐商品中的 SKU。检查用户工作目录内同商品 manifest、图片和状态；完整结果必须实际打开并通过当前验收，文件数足够不能单独证明完成。复用已通过图片，仅继续缺失或失败部分。

登录过期时保留正确页面供用户登录，继续不依赖登录的工作。不得读取、复制或保存密码、Cookie、Token、localStorage 或 sessionStorage。

## 2. 提取可信参考

仅使用主商品左侧的大图及其直接下方缩略图。先确认选中的缩略图，再复制/导出对应的大图；使用宿主实际提供的保存图片或元素截图能力，不能臆造剪贴板接口。

- 排除推荐商品、选项色块、店铺标志、横幅和页面 UI。
- 若复制失败，重新读取页面状态后最多一次有依据重试；可用时导出该主图元素。不能用整页截图裁切冒充原始产品图。
- 只有用户已配置自己的 GigaB2B OpenAPI 且允许使用时，才改用 [API 素材流程](../etsy-tony-full-gigab2b-assets/SKILL.md)。
- 每张保存后用 `view_image` 查看，确认商品一致、视角正确、无 UI 污染且不重复。只保留可信图片。
- 原站存在多个有效角度时充分保留，优先五张以上；原站更少时记录缺口，不伪造角度或强行凑数。只有缺失信息影响本轮保真时才询问。
- 尺寸必须来自该商品已确认数据，区分商品尺寸和包装尺寸；看不清时保留 Unknown。

写入 `manifest.json`、`product-title.txt` 和 `reference-images/`，记录来源、商品身份、采集时间、每张图的提取方法和视觉验证结果。不得把原始参考称为生成成品。

## 3. 建立完整摄影计划

读取 [镜头组合](references/shot-mix.md) 和完整摄影引擎，交接：商品事实、所有已验证参考、锁定细节、真实尺寸来源、所需数量和买家关注点。

完整参考集用于理解商品；每次生成选最能证明该镜头细节的 2–4 张原图，并遵守工具输入上限。不要为了塞入所有图片制作低清拼图。

计划包含主图、完整产品、真实使用、远中近角度、部件和材质细节、比例及适用的尺寸图。细节图应处于合理场景，不能全部成为白底裁切。人物或宠物只在品类安全、比例可信且能说明使用时出现，不按配额加入。

尺寸图有真实数值时保持精确，用确定性方式排版数字与尺寸线；没有尺寸时制作不带数值的比例场景并注明限制。若用户明确要求精确尺寸图，该张在补齐数据前保持 BLOCKED。

## 4. 实际生成并验收

由完整摄影引擎保存整套计划与每张提示词，先生成第一张并实际看图，再逐张继续。每张独立生成；不要将 15 格拼图当作 15 张商品图。

保留已通过图片。网络错误时先检查是否已经产出文件；没有产出才用更少参考与更短提示词重试一次。仍失败则保存可恢复记录，准确说明阻塞。

逐张对照原图核对结构、数量、材质外观、颜色、文字、五金、比例及镜头任务。失败图片不能计入完成数量。对用户指出的失真重新验收，不用内部评分否定用户的具体证据。

## 5. 保存与交付

优先用户指定目录，否则使用当前项目 `etsy-output/<product-id-or-sku>/`：

```text
manifest.json
product-title.txt
reference-images/
plan.codex-direct.json
prompts/shot-01.txt ...
final-images/final-01.png ...
fidelity-audit.json
upload-handoff.json
```

用 ASCII 文件名，保留旧版本。保留内容来源信息；只有用户要求清除意外个人元数据时才做相应导出，并验证像素未变。默认交付目录，不自动 ZIP。

`upload-handoff.json` 记录 product_id/SKU、源 URL、最终文件列表与 SHA-256、数量、尺寸来源、每张验收状态和输出位置。`manifest.json` 记录 `generationSkill: etsy-tony-full-photo-engine`，只有数量与全部验收通过才标 `generationStatus: complete`。这只是图片交付，不能代表已上传或发布商品。

简短汇报商品、实际生成数量、输出目录、尺寸验证和缺失/重做的图号，显示实际可打开的结果。不要自动联系他人或执行后续店铺写入。
