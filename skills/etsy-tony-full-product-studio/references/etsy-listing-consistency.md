# Etsy Listing and Consistency Rules

## Runtime official-rule check

Verify platform fields against current official Etsy documentation at every launch-pack run. As checked on 2026-08-31:

- Etsy Help, How to Create a Listing: https://help.etsy.com/hc/en-us/articles/115015628707
- Etsy Help, How to Offer Personalized Listings: https://help.etsy.com/hc/en-us/articles/360000344528
- Etsy Help, How to Add Variations: https://help.etsy.com/hc/en-us/articles/115015664047
- Etsy Seller Handbook, Keywords 101: https://www.etsy.com/seller-handbook/article/382774281517

At that date official guidance said a title can be up to 140 characters, a listing can use up to 13 tags, listing variations cover up to two attributes, and personalized fields/option lists serve different purposes from inventory/price/SKU variations. Record the current verification date; if the page cannot be read, use Platform Rule Verification Required.

The user's standing rule is exactly 13 English tags separated by English commas. Each tag must be accurate and within the current official per-tag limit.

## Listing pack

For recommended SKUs provide US-English title, one-line positioning, benefits, description, use, Gift For, Occasion, Materials, personalization instructions, recommended variations, personalization field text, tags, attributes, and a selective image plan.

## Image plan fields

For each Hero, Close-up, Personalization, Pattern/Font/Color chart, Size, Placement, Material, Process, Lifestyle, Packaging, How to Order, Care, or comparison image, state purpose, evidence shown, visual focus, suggested copy, numbering, measurements, option code, and disclaimer.

Do not mechanically require every image role. For personalized commercial products, follow the current Etsy rule for primary-image finished-item evidence. Mockups or option diagrams in supporting images must not imply unverified material, dimensions, color, or production quality.

## Final consistency check

- Product in images = title/description Product.
- Every shown P/F/C option exists and can be made.
- Material, process, size, and finish are confirmed or disclosed.
- No title/tag claims nonexistent features.
- Personalization collects every production input.
- Customer can order from images and fields without guessing.
- Props/accessories not included are disclosed.
- Codes match the option matrix, manufacturing card, and production files.
- Placement and Production Process remain correctly classified.

Do not publish; the launch pack is a draft until separately authorized.
