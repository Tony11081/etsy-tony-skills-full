# 15 个镜头角色与视角规划

规划或重新规划 15 图时读取。先完成 [category-adaptation.md](category-adaptation.md) 的买家问题与证据映射，再分配角色和视角。

## 买家旅程角色模板

这是可替换的角色图，不是固定构图清单。角色缺证据时按 `role_substitutions` 用类目原生证据替代，但保留买家旅程、不重复。

1. `hero`：完整成品，一眼可辨，事实准确，缩略图尺寸下清晰。
2. `what_you_receive`：完整产品或整套清单，内含物准确。
3. `size_and_scale`：有尺寸时用锁定数字；否则用真实比例关系。
4. `variations`：颜色、材质、表面、形状、字体、款式等可见选项（若有）。
5. `material_and_craft`：纹理、表面、边缘、缝线、五金、印刷、雕刻、构造证据。
6. `personalization_or_unique_value`：已完成的个性化，或最强的类目差异点。
7. `use_or_lifestyle`：证明使用、合身、氛围或买家结果的自然情境。
8. `back_inside_or_structure`：主图无法展示的重要区域（**仅当参考图有**）。
9. `packaging_and_gifting`：实际包装与送礼状态（**仅当已核实**）。
10. `process_or_provenance`：真实制作、加工、个性化或年代证据（**仅当有支撑**）。
11. `installation_care_or_use`：如何安装、拿取、佩戴、清洁、使用。
12. `limits_and_exclusions`：不包含的道具、颜色/尺寸提示、兼容性等决策关键限制。
13. `alternate_angle_or_state`：真正新的角度、配置、开合、运动或部件关系。
14. `category_specific_trust`：合身、容量、扣件、底部、标签、瑕疵、厚度、洗后效果、到货状态等类目原生证据。
15. `premium_closing_context`：真实且不改变产品的收尾图，强化拥有、送礼或使用。

前五张通常应建立：产品身份、内含物、尺寸/比例、可见选项、品质。不把排除项和重大限制藏在最后。

常见替换：无包装证据 → 第二个决策关键证据（扣件、容量、表面、状态、兼容性、部件关系）；无工艺证据 → 受支持的材质/构造/变体/使用状态；无背面/内部参考 → 有来源的边缘、连接、侧面或更完整的清单视图；无精确尺寸 → 类目安全的比例线索并标 `scale_effect`，不生成数字；数字产品 → 用内容、页面预览、格式、软件兼容性替代实物生活/发货/包装角色；无实际人物使用 → 状态、部件、兼容性、安装间距等事实证据。

## 视角规划门

在拍摄计划阶段设计视角，而不是留给生成或最终审查。顺序：先确定产品形态、有来源的面/状态、自然使用方式、买家问题；再分配能揭示这些答案的视角；最后才配场景和道具。一串场景名加"多角度"不是完成的拍摄计划。

### 每张图的 `view` 与 `visible_view_cues`

`view` 一句话必须同时回答：产品哪个面朝相机、相对支撑面如何转动/倾斜、相机方位与高度、距离（整体/情境/中景/近景/细节）与裁切重点。产品转向和相机位置要一起规划——两者同时动可能恰好还原同一个产品-相机关系。"三分之一侧面"若没说明哪一侧、预期哪个面变得可见，就不够。

`visible_view_cues` 写该视角成立时画面里能被审计者核对的证据，例如：某个已有来源的侧面/顶面/底面露出、两个面的相对宽度、边缘遮挡顺序、透视缩短方向、受支持的合身/放置关系。反光产品还要写该朝向下合理的反射位置；只有反射变了不算角度变了。

### 按产品类型选视角（选择指南，不是配额）

| 产品/证据类型 | 有用的视角决策 |
| --- | --- |
| 刚性三维物、家具、工具 | 有来源的各面、连接处、深度关系、放置、操作视角 |
| 服装、织物、柔性品 | 受支持的穿着/平铺/悬挂状态、身体相对视角、垂坠、合身、折叠与构造细节；不虚构背面设计或合身效果 |
| 首饰与小配件 | 有来源的轮廓、镶嵌、闭合、表面细节，以及可信的佩戴关系 |
| 平面艺术、标牌、印刷品 | 保留可读的整体视图；加受支持的表面、边缘、安装或陈列关系；不为凑角度虚构厚度或背面 |
| 套件、多件组 | 变换部件焦点、布局、接口、组装/使用状态，保持内含物真实 |
| 数字产品或对角度不敏感的主体 | 用实际页面/内容、工作流步骤、布局与细节框；物理朝向字段写 `not_applicable` 并说明；设备旋转不是新内容证据 |

对称性、来源覆盖和买家问题决定哪些视角变化有意义。没有对所有产品适用的固定角度数、度数值、左右后顺序或斜视角比例。**只有正面参考图不能证明隐藏的厚度、五金、支撑或背面构造。** 想要的视角缺证据时，选受支持的替代并把缺口记入 `restricted_views`；不通过虚构几何强行出新角度，也不默默宣称角度覆盖完成。

### 整体预检

写 prompt 之前，把 15 个 `view` 放在一起看，忽略背景、场地、色板、名字/编号变化：

- 距离/裁切变化能增加细节证据，但本身不是新视角；一张图的 2D 旋转、翻转、透视变形不是新观察到的产品表面。
- 若普通展示镜头全部用同一个姿态/视角，而所需信息本可由受支持的替代视角展示，现在就改，不靠换场景名修补。
- 为有来源的选项、测量、步骤或不同细节保留匹配视角是合理的，写 `reuse_group` + `reuse_reason`；对称物或证据有限的产品可合法共享视角，但记录原因并保留未满足的买家问题作为缺口。
- 证据撑不起 15 个有用角色时，保留受支持的计划并报 `PARTIAL` 或 `BLOCKED`，不填充。

预检通过后，把每张图的姿态、朝向、相机、框取、可见线索原样带进自包含的 prompt。保留产品身份与来源细节，允许规划的视角；除非用户要求或文档化的比较需要，不把参考照片的相机角度锁在整套图上。
