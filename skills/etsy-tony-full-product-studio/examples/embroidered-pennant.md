# Embroidered Pennant — PROCESS and DESIGN Example

## Input

Product: personalized fabric pennant. Known equipment: Brother PR1000E. Fabric, stabilizer, hoop, size, thread stock, and tested minimums are Unknown / To Be Tested.

## Evidence and Product

Observed Fact: product category and intended embroidery process come from the brief. Reasonable Inference (Medium): the pennant may include a hanging edge and pointed lower zone. Unknown: fabric fiber/weight/stretch, construction, size, seam allowances, rod system, exact viewing distance, and machine configuration.

Buyer job: display a personalized name or short phrase as decor or a gift. Main risks: illegible small text, puckering, off-center placement, low contrast, and a long name that breaks the composition.

## Architecture and Zones

| Zone | Function | Decoration decision |
|---|---|---|
| Main Body | primary viewing field | main motif and name after hoop/size confirmation |
| Upper Edge | hanging or rod channel may exist | keep clear until construction measured |
| Lower Point | narrow and distortion-prone | accent only; no long text |
| Left/Right Margins | seams and alignment | maintain tested safe area |
| Back | finishing/stabilizer view | not a default artwork surface |

## Manufacturing Gate

- Material–Process: fabric + Embroidery = Sample Test Required.
- Artwork: ordinary PNG/vector is source art, not production art; Digitization Required.
- Primary Process: Embroidery.
- Secondary: fabric cutting/sewing if produced in-house; otherwise Unknown.
- Finishing: trims, backing/stabilizer cleanup, pressing only if tested.
- Assembly: hanging channel/hardware Unknown.
- Packaging: prevent crushing and thread snagging.
- Gate: CONDITIONAL PASS.
- Production Approval: Awaiting Machine Parameters.

Allowed language: clear fills, stable outlines, moderate color changes, readable lettering. Requires Translation: watercolor, hairline illustration, dense hatching, gradients. Not recommended before tests: fine script at small size, highly detailed thin line art, many close thread colors.

## Design Family Rule

One valid family could use bold folk shapes, rounded humanist lettering, two or three high-contrast thread colors, centered/arched name hierarchy, and generous margins. Do not mix it with fine Victorian calligraphy merely to add variety.

## Size and File Rule

Different physical sizes may require separate digitized files, stitch paths, density/pull compensation, and testing. If that changes file/setup/QA materially, use Separate SKUs S01/S02 rather than one uncontrolled scaling option.

## Option Control

- Pattern: P01–P03 only if each is separately digitized and tested.
- Font: F01 Rounded Sans; F02 Simple Serif. Fine script is Not Offered until sample proof.
- Thread color: only stocked high-contrast choices; low-contrast fabric/thread pairs invalid.
- Placement: Fixed at tested main-body position.
- Name: personalization input, not a new SKU.

Dependencies: long names switch from arched to horizontal layout; small pennant rejects high-detail motifs; each size selects its own embroidery file; dark fabric requires a light tested thread; untested characters require proof.

## Sample Plan

Test fabric/stabilizer/hoop, short and 15-character names, double names, smallest proposed letters/counters, high-detail motif, thread contrast, position repeatability, puckering, reverse cleanup, wash/handling if the use requires it, and packaging compression.

## QC

Check SKU/file, position, thread colors, breaks/skips/floats, puckering, small text, reverse cleanup, stabilizer, trims, long-name layout, seam clearance, and final packaging.

Result: reusable design path exists, but no production approval until the material and digitized samples pass.
