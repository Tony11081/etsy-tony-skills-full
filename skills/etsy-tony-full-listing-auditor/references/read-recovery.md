# 已有页面与读取故障恢复

读取 listing 失败、字段缺失或用户说“页面已经打开”时读取本文件。

- **利用已连接的 Etsy 只读工具。** 浏览器读取失败或缺少字段时，精准查找现有 Etsy 连接器是否支持按 listing ID 获取资料。若有 `etsy_displayetsylistings`，可按其当前工具说明传入用户指定的单个 ID（手工指定列表，无需先搜索）；面向美国审查可指定 `buyer_country: "US"`、`currency: "USD"`，按接口要求展示结果。只使用实际返回的标题、描述、tags、图片链接等字段，不假设工具一定提供完整数据。`tags` 字段可以作为实际标签证据；`taxonomy_id` 不等于已知类目名称，价格与运费不等于已选变体的结账价。记录来源、时间、地区参数及缺口，引用干净商品 URL，不传播返回 URL 中的会话参数。图片链接仍须实际看过像素才能形成视觉结论。不要为读取商品建立无关项目。
- **先复用页面。** 已有目标 URL、标签页 ID 或 mention 时，按当前工具文档选择对应连接入口，不先新建标签页，也不默认让用户重新打开、再次 @ 或提供截图。使用 `cua_repl` 且已知内置浏览器 URL 时，可用 `await cua.getTab({ url: targetUrl }, { browser: "iab" })`；首次调用或重置后只执行允许的入口调用，先读返回文档再操作。仅在缺少定位信息时读取浏览器/标签页清单，不抓取无关页面正文。
- **分清故障位置。** 标签页未找到、工具连接超时、站点 HTTP 403、页面登录/验证码及工具安全停止分别记录。连接超时不能证明页面未打开、商品下架或站点拒绝；HTTP 请求被拒绝也不能证明现有浏览器页面不可读。用户说“已经打开”后，先核对现有连接信息，不重复要求其完成相同动作。
- **有限自主恢复。** 超时后先按工具支持的方式重新连接并回读当前状态；同一瞬时错误最多进行一次有依据的重试。工具已自动重置时按首次调用规则恢复，不再叠加重置；更换 URL 尾缀、重复创建标签页或改调用名称不重置重试次数。恢复仍失败时，在工具允许范围内检查独立的只读入口（已登录 Chrome、公开网页正文/图片读取）。只发现相关工具；单个 CLI 缺失不等于 Chrome 不可用。不为本次审查默认安装工具、创建后台服务或修改浏览器配置。
- **遵守停止条件。** 登录或验证码需要用户处理时停止该路径；工具因安全检查拒绝操作时，遵守其明确范围，不用其他工具、截图、脚本或会话重置绕过。若工具要求停止本回合并回复，立即照做。只描述实际被阻止的动作和返回原因，不把已读到的其他证据一并作废。
- **最后才请求必要介入。** 在允许的恢复及可用只读替代路径均失败，或确有必须由用户处理的登录/验证码等条件时，才说明准确阻塞与最小解锁动作；已有 URL 不应再以 @ 标签页作为通用修复。需要补资料时只索取阻塞结论的最少字段或图片。可完成的部分继续交付并标 `PARTIAL`；无法实质推进才标 `BLOCKED`。浏览器已打开、工具可调用、Skill 已修改和商品正文已成功回读是不同验收结果，不能相互替代。
