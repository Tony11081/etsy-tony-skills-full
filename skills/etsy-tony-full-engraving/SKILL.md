# Etsy Cake Knife Server Design

## 当前任务与交付

- 材料：本次要设计或替换的刻字、可读文字及产品图；需要用户提供自己的产品底图，沿用当前对话已有图片。
- 范围：按设计稿或产品效果图区分产物；只改金属刻字区域时，刀柄、刀刃、锯齿和背景保持原样。
- 验收：核对刀与铲映射、所有文字和产品细节；效果图不是可直接加工的矢量文件。


Use this skill to create cake knife/server engraving concepts, layout directions, Etsy listing support, or product mockups. Use the actual product photo supplied by this user as the locked product reference; this public package does not bundle a private house-product photo.

## Core Workflow

1. Identify the requested deliverable:
   - Concept system: market positioning, product series, design families, recommended samples.
   - Layout variants: 10 or more distinct engraving patterns for one concept.
   - Product mockups: place approved engraving designs on an outline template or real product photo.
   - Fixed-product mockups: reuse the supplied product base. If only a design image is available, ask for the real product photo before compositing; do not invent its construction.
   - Listing support: selling points, personalization copy, tags, and variant structure.

2. If the user asks for current trends, bestsellers, competitor patterns, market validation, or what will sell now, verify with current web research before making market claims. Prefer Etsy search/category pages, wedding gifting pages, Pinterest or wedding visual sources, and recent product examples. Do not copy existing seller designs.

3. Use the cake server as the primary visual area. Put the most emotional or readable content there: monogram, surname, large age number, main phrase, family name, venue, or central floral/line frame.

4. Use the cake knife as the secondary line. Put date, location, "Established 2026", "The Parkers", "Make a Wish", or a short companion phrase. Keep knife text shorter than server text.

5. Design for real stainless-steel laser engraving:
   - Use monochrome line art, vector-friendly type, no gradients, no shadows, no complex fills.
   - Keep text short and readable after engraving.
   - Use generous margins inside blade/server outlines.
   - Avoid thin ornamental details that will disappear on reflective metal.
   - Recommend vector redrawing and font license checks before production.

6. When producing multiple images, first lock the design system, then generate or compose each output from that locked layout. Check every image against the approved pattern. If image generation drifts from the pattern or changes the product, regenerate with stricter product-lock language before trying a different approach.

## Output Shape

For concept work, include these fields for each design:

- Product category
- Main market
- Target buyer
- Buying motivation
- Occasion
- Core design idea
- Cake server design
- Cake knife design
- Personalization fields
- English engraving examples
- Font direction
- Layout structure
- Graphic elements
- Laser engraving feasibility
- Etsy selling point
- Variant potential
- Priority sample recommendation

For quick 10-variant design tasks, make every variant differ in at least two ways: information hierarchy, visual center, typography mix, graphic language, layout direction, target customer, use scenario, personalization method, or the relationship between knife and server.
