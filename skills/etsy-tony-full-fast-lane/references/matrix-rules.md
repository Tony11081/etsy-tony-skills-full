# 四维规则（载体 × 主题 × 工艺 × 风格）

新产品按四个维度各取一条。没有的条目现场补上并写回本文件，下次直接用。

## 载体 → 摆法与比例参照物

| 载体形态 | 摆法 | 比例参照物 |
|---|---|---|
| 小件平面（纸牌、卡片、贴纸、书签） | 平铺俯拍、扇形展开、手持、放在盒子旁 | 手、笔、咖啡杯 |
| 悬挂类（圣诞袜、挂饰、挂旗） | 挂在壁炉、墙钩、树上；平铺 | 壁炉台、门、椅背 |
| 立放类（桌牌、相框、摆件） | 立在桌面，与餐具花艺同框 | 餐盘、酒杯、蜡烛 |
| 布艺家居（抱枕套、窗帘、桌布） | 用在沙发、窗、餐桌上的实景 | 沙发、窗框、椅子 |
| 穿戴类（衣服、帽子、围裙） | 上身、平铺、挂拍 | 人体 |
| 墙面类（装饰画、海报） | 上墙实景、靠墙立放 | 沙发、边柜、门 |

真实尺寸取自出图单；参照物只用来让人看出大小，产品不能比参照物该有的比例大或小。

## 主题 → 场景与氛围

| 主题 | 场景 | 氛围 |
|---|---|---|
| 婚礼 | 接待桌、宴会桌、花艺、亚麻布 | 自然窗光，柔和 |
| 圣诞 | 壁炉、圣诞树、暖灯、礼物 | 暖色，有节日气息 |
| 新生儿/儿童 | 婴儿房、木质玩具、浅色软装 | 明亮干净 |
| 家居日常 | 真实的客厅、厨房、卧室一角 | 有生活感，不要样板间 |
| 送礼 | 礼盒、丝带、手写卡、拆礼物的手 | 有「收到礼物」的瞬间 |
| 派对/游戏夜 | 桌面、酒杯、朋友的手 | 轻松热闹 |

## 工艺 → 材质表现

| 工艺 | 画面里要看得出 |
|---|---|
| 高光铜版纸印刷 | 表面有柔和反光，边缘利落，颜色饱和 |
| 数码印花涤纶 | 布面细腻有织纹，图案随褶皱自然变形，底色不偏 |
| 刺绣 | 线迹有凸起和走向，高光落在线上 |
| 激光切割/雕刻木 | 切边微焦，木纹清楚 |
| 镜面亚克力 | 有环境反射，但字仍然可读 |
| UV 打印 | 表面平整，略有浮雕感 |

## 风格 → 设计方向

风格跟对标款走：对标款是什么风格，就做那种风格。下面是常见叫法，方便记录：经典字母徽章、Art Deco 几何、植物线稿、复古花边、极简衬线、条纹海岸风、艺术家风格（纹样、水彩、版画等）。
