# eRank API 证据

使用者已有授权连接或可追溯导出时，可以用真实 eRank 数据支持选词。通过当前环境已配置的连接读取。按已授权的市场和关键词范围查询，先复用已有结果。关键词查询可能消耗额度。

每个词记录关键词、市场、来源、实际采集时间、缓存状态，以及平均搜索量、平均点击量、CTR 和竞争度的原始显示值。保留 `< 20`、`Unknown`、`-` 和空值。来源只覆盖种子词时，仅该词计入实测覆盖。

来源、市场或词无法核对时，将数据标为不可用。没有授权连接且需要相关词或原标签时，按 [eRank 浏览器读取说明](../../etsy-tony-full-erank-tools/references/keyword-tool-browser.md) 操作。查询超时或额度未知时保留已获数据，暂停新增查询，避免跨入口重复提交。基于商品事实生成的未实测词标为“模型建议，非 eRank 实测”。
