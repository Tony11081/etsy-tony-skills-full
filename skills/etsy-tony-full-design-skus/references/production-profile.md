## Confidence Labels

- Documented: 来自设备正式资料

## Global Rules

1. 本文件只用于判断 Current In-house Capability。
2. 本文件不得限制 Ideal Manufacturing Process。
3. 未明确记录的能力或参数一律视为 Unknown。
4. 不得根据模型知识自动补全设备参数。
5. 普通产品分析不得自动修改本文件。
6. 只有用户明确要求更新生产档案时才允许修改。
7. 每次更新必须记录：
   - Updated Field
   - Previous Value
   - New Value
   - Evidence Source
   - Test Date
   - Updated By
