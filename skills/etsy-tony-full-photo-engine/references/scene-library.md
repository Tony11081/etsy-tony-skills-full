# 场景库：什么产品配什么画面

写 `art_direction` 时读取。先读完 [art-direction.md](art-direction.md) 第 1、2 节，带着 `product_reading` 和 `buyer_reading` 来这里选：**一个产品家族 + 一个场合（如果有）+ 一种风格**，把选择记在 `art_direction.library_entry`。

画面拍成什么构图（单品、成排、上手、使用中、平铺、近景……）在 [composition-library.md](composition-library.md)，按卖点去选；本文件只管在哪拍、什么光、什么颜色。

这是起点，不是模板。每一条都要用当前产品过一遍：`product_reading` 里找不到依据的线索删掉，产品有而这里没写的特点补上。只需要读对得上的那一条家族和用到的场合、风格，不用通读。找不到对应家族时，按 art-direction 第 1 到 4 节自己推一条，同样写进 `art_direction`。

所有条目都受保真和事实规则约束：道具不暗示包含在内，不虚构包装、工艺和尺寸，人物只在预算内出现。

## 一、产品家族

### 节日袜与节日挂饰（圣诞袜、挂件、树裙、花环）

- **买家那一幕**：平安夜前，全家每人一只，按名字挂成一排。奶奶给孙辈买、妈妈给全家买、新婚第一年、宝宝第一个圣诞，宠物也有一只。
- **世界**：A 壁炉台，白漆或原木的 mantel 加新鲜雪松花环。B 楼梯扶手上挂一排。C 没有壁炉的家：玄关挂钩、靠墙木梯、床尾、窗下长凳（很多买家家里没有壁炉，这一类最容易让她代入）。D 圣诞早晨的树下。
- **光**：傍晚窗光从侧面低角度扫过，绒面和毛口才有层次；远处的树灯、串灯虚成光斑。打在袜子上的光保持中性，暖只在背景。`mood_profile` 通常是 `warm_scene`。
- **色板**：白或奶白的墙，深绿，一点黄铜或原木。袜子是最浓的颜色；红袜不放在红背景前。
- **道具**：雪松或冷杉枝、松果、黄铜挂钩、牛皮纸包的礼物、木珠串、一杯热可可。产品旁边每张最多三样；背景和前景的场合信号另算，按 [atmosphere.md](atmosphere.md) 的级别配。
- **主图**：`L3`。背景里有亮灯的树或灯串的光斑，台面上有花环，前景或一侧有礼物，袜子是装了东西的。成套卖的拍一排（三到五只，名字都朝镜头、都读得出）；单只卖的正面拍，袜口的名字落在画面上三分之一，整只完整入画，自然垂坠、略微鼓起。
- **人**：够袜子的小手，往袜子里塞礼物的手。不露脸。
- **别这样**：炉火正对产品把颜色烧黄；灯串糊满全屏；圣诞老人和卡通元素；名字被花环挡住；袜子瘪平地贴在墙上。

### 个性化首饰（名字项链、生辰石、戒指、手链）

- **买家那一幕**：生日、纪念日、母亲节、伴娘礼，或者奖励自己。打开盒子的一瞬间，和每天戴在锁骨上的样子。
- **世界**：A 晨光里的梳妆台一角，石托盘、亚麻。B 佩戴：锁骨、手、耳，配浅色针织或白衬衫。C 礼盒刚打开。
- **光**：大面积柔和窗光加白卡补光，金属高光是干净的渐变。`true_color`：金要像金，银要像银。
- **色板**：暖白、燕麦、浅石灰和肤色，一点绿或干花。
- **主图**：佩戴近景，或石面、亚麻上 45° 近摄。刻字朝镜头、读得出，首饰占画面一半左右。
- **人**：佩戴图最有说服力。只拍局部，皮肤有真实纹理。
- **别这样**：放大到失真；戒指盒堆出来的假奢华；反光里有杂物；柔焦糊掉刻字；黑丝绒底的老套路。

### 婚礼用品（蛋糕刀铲、桌号、指示牌、戒指盒、签名册、伴娘礼）

- **买家那一幕**：婚礼当天被用到的那一下，和婚后留作纪念的样子。买的人是新娘、新娘的妈妈或伴娘。
- **世界**：A 户外花园长桌。B 明亮宴会厅一角的蛋糕台。C 备婚的桌面平铺：请柬、丝带、干花。
- **光**：明亮通透的日光，高调但有影子。通常 `true_color`；傍晚的串灯只做远处背景。
- **色板**：白、象牙、鼠尾草绿，加一种婚礼色（淡粉、灰蓝、赤陶）。金属色克制。
- **道具**：当季真花、蛋糕、亚麻桌布、丝带、手写卡。
- **主图**：刻字或桌号正对镜头、清晰。刀铲放在蛋糕旁 45°，不插在蛋糕里。
- **人**：两只手一起握刀，只到手腕和袖口。
- **别这样**：塑料感的假花；蛋糕比产品抢眼；整屏暖黄；刻字看不清。

### 婴童与育儿（宝宝毯、名字牌、里程碑卡、童装、布玩具）

- **买家那一幕**：迎婴礼、满月、第一个生日。新手父母布置婴儿房，或者姑姑阿姨挑礼物。
- **世界**：A 婴儿房：小床边、摇椅、柔软的地毯。B 铺开的毯子上俯拍平铺。C 礼盒和丝带。
- **光**：上午柔和的窗光，高调、低对比、干净。`true_color`。
- **色板**：奶白、燕麦，加一种低饱和的鼠尾草绿、灰蓝或藕粉。产品上的名字是画面里最清楚的东西。
- **道具**：木玩具、藤篮、布书、小袜子。
- **人**：宝宝的小手小脚，裹在毯子里的背影。不露脸。
- **别这样**：塑料玩具堆；卡通形象；偏暗；任何不安全的摆法（毯子盖着脸、小床里堆满东西）。

### 木制与雕刻礼品（砧板、名字牌、杯垫、激光切割件）

- **买家那一幕**：乔迁、新婚、父亲节、圣诞。它会被摆在厨房台面或玄关，天天看得见。
- **世界**：A 厨房台面，白砖墙或石台面。B 玄关柜、书架上陈列。C 餐桌上真的在用：面包、奶酪、香草。
- **光**：低角度侧光把木纹和刻痕的深度扫出来。日常场景 `true_color`；节日餐桌可以 `warm_scene`。
- **色板**：白或浅灰石，绿（香草、橄榄枝），木色只来自产品。
- **主图**：刻字正对镜头，或 30° 斜靠在墙上，字清晰。
- **别这样**：木台面托木产品，整屏棕色；刻字被食物盖住；亮得发假的清漆感。

### 家居装饰与墙面艺术（挂画、标牌、抱枕、摆件）

- **买家那一幕**：布置新家、换季、给一面空墙找东西。
- **世界**：沙发上方、玄关柜上、床头、书架。真实房间的一个角落，画和家具的比例是对的。
- **光**：白天侧窗光，墙上有柔和的明暗渐变。
- **机位**：正对墙面、垂直线竖直；另配一张斜侧面看厚度和质感。
- **色板**：从作品里取一两个颜色，呼应到抱枕、花或书脊上。
- **别这样**：空房间 mockup；画大得像壁画；透视歪斜；家具全新、没人住过。

### 厨房与餐桌（杯子、围裙、餐巾、桌旗、餐具）

- **买家那一幕**：请朋友来吃饭、早晨第一杯咖啡、节日大餐。
- **世界**：A 早餐桌。B 摆好的餐桌俯拍。C 厨房岛台上，做到一半。
- **光**：晨光或白天窗光。晚宴可以用烛光做背景点缀（`warm_scene`）。
- **道具**：真食物，量少、新鲜、不抢戏。
- **别这样**：食物比产品好看；杯子空着（要有内容物和一点使用痕迹）；餐具悬浮。

### 服装与刺绣（卫衣、T 恤、帆布袋、帽子）

- **买家那一幕**：送新妈妈、闺蜜、情侣、毕业生，或者自己穿出态度。
- **世界**：A 穿着，颈部以下或背影，在咖啡馆、街角或家里沙发上。B 平铺在亚麻或木地板上，配牛仔裤、鞋、小物。C 木衣架挂在白墙前。
- **光**：柔和日光；刺绣要侧光，线迹才立体。`true_color`，衣服颜色必须准。
- **主图**：图案或刺绣正对镜头、清晰、在画面中心。
- **别这样**：图案被褶皱吃掉；塑料模特；刺绣糊成印花；修身到失真。

### 包袋与皮具（钱包、卡包、钥匙扣、手提包）

- **买家那一幕**：父亲节、毕业、周年礼。每天摸得到的东西。
- **世界**：A 书桌或玄关托盘上的随身物。B 从口袋里拿出来、手里握着。C 工作台上的工艺特写。
- **光**：侧光显粒面和缝线。可以稍暗调，但产品在最亮处。
- **色板**：深木、石、羊毛灰、牛仔蓝，皮色是主角。
- **别这样**：成堆的钞票；塑料光泽；刻字不清。

### 宠物用品与宠物纪念

- **买家那一幕**：给毛孩子的；或者纪念离开的它。
- **世界**：家里它常待的地方：门口、沙发、它的窝。纪念品放在窗台或书架上，旁边是一张照片或它的项圈。
- **光**：自然光。纪念类用柔和安静的侧光，克制，不煽情。
- **人与宠物**：宠物入镜要毛发真实、比例正确。容易抢戏或出错时，改用隐含的存在：牵引绳、爪印、空着的窝。
- **别这样**：卡通化的宠物；表情诡异；纪念品配鲜艳喜庆的颜色。

### 文具纸品与请柬

- **世界**：以俯拍平铺为主：纸、信封、丝带、火漆、干花。几何对齐或自然散落，二选一。
- **光**：柔和侧窗光，带淡淡的长影，纸的肌理看得见。`true_color`。
- **别这样**：生成的字是乱码（文字用参考原样或确定性叠加）；全平无影；道具压在字上。

### 蜡烛、香氛与身体护理

- **世界**：浴缸边、床头、茶几。石、陶、亚麻。
- **光**：柔光。点燃的蜡烛只有烛火本身是暖的，周围保持中性。
- **别这样**：烟雾特效；标签上的字糊掉；塑料感的水珠。

### 家具与大件

尺度、人物和住过的痕迹按 15 图 Skill 的 furniture-scale.md。审美上只补三点：白天的自然光；真实住过的房间，不是空展厅；少放东西，让家具自己说话。

### 数字产品与 POD 底品

实物感来自真实的载体：真实的设备、纸张、相框、底品，内容清楚可读。不暗示实物发货。底品的颜色、印刷位置和尺寸必须和实际一致。

## 二、场合层

有明确场合时叠加。证据图挑一两样；主图和场景图要让人一眼认出场合，按 [atmosphere.md](atmosphere.md) 第 3 节的级别配信号、光和人的痕迹，各场合完整的氛围清单在它的第 7 节。

| 场合 | 色与光 | 可选线索 |
| --- | --- | --- |
| 圣诞与冬季节日 | 深绿、红、白、黄铜；傍晚侧光，远处灯串成光斑 | 雪松枝、松果、包好的礼物、热可可 |
| 情人节、周年 | 柔粉、酒红、白；清晨柔光 | 手写卡、一两枝花、丝带 |
| 母亲节、春季 | 明亮通透；淡绿、奶白、花色 | 当季鲜花、茶、早餐托盘 |
| 婚礼季 | 白、象牙、鼠尾草绿；高调日光 | 真花、亚麻、丝带 |
| 迎婴、新生儿 | 奶白和低饱和的粉蓝绿；上午柔光 | 木玩具、藤篮、小衣物 |
| 父亲节、毕业 | 深蓝、皮棕、灰；稍硬的侧光 | 手表、书、咖啡 |
| 秋季、感恩节 | 南瓜橙、焦糖、深绿、奶白；低角度午后光 | 小南瓜、干叶、格纹毯 |
| 万圣节 | 黑、骨白，加南瓜橙或暗紫；暗调但产品亮 | 蜡烛、干枝、南瓜 |
| 纪念、缅怀 | 安静的中性色；柔和侧光，留白多 | 一张照片、一枝花 |
| 乔迁 | 明亮日光；白、木、绿植 | 钥匙、纸箱一角、绿植 |

## 三、风格层

风格跟着 `buyer_reading.taste` 和产品的定位选，不是哪个流行选哪个。同一家店的图尽量用同一种。

| 风格 | 表面与材质 | 光与色 |
| --- | --- | --- |
| 现代农舍 | 白墙板、原木、黑铁、亚麻、绿植 | 明亮侧窗光；白、木、黑 |
| 北欧与日式自然 | 浅木、白、灰、陶；留白多 | 漫射柔光；低饱和 |
| 传家怀旧 | 旧木、蕾丝、碎花、黄铜、瓷 | 柔和侧光；奶白和褪色的暖色 |
| 经典传统 | 深木、格纹、丝绒、黄铜 | 较浓的侧光；深绿、酒红 |
| 波西米亚 | 藤、流苏、陶土、干花 | 柔光；暖中性色 |
| 现代极简 | 白或浅灰、石、单一色块 | 稍硬的光，影子清晰 |
| 暗调氛围 | 深色墙、深木 | 单侧窗光，阴影浓；产品在最亮处 |
| 海岸 | 白、沙色、淡蓝、漂流木 | 通透日光 |
| 童趣多彩 | 饱和撞色、图案叠图案 | 明亮均匀的光；产品仍然最跳 |
