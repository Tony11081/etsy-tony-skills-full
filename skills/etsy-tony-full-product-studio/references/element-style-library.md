## Expansion procedure

For every proposed style answer:

1. Does it serve the Product and buyer occasion?
2. Does it match material character?
3. Can the process express its essential qualities?
4. Does it coexist with typography, color, composition, and placement?
5. Does it create enough originality distance?
6. Does it require translation, a separate file, or sample test?

Only styles that pass these questions enter a Design Family.

## Anti-combination rule

Do not combine every motif, font, color, and placement. Build a family narrative, define allowed roles and prohibitions, then select the smallest set that supports it. A motif species swap inside the same structure is usually P01/P02/P03, not a Base SKU.
