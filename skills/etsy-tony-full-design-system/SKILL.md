# Etsy Design System Builder

## 当前任务与交付

- 材料：产品与买家证据、工艺 gate 的结论和限制、已选方向或参考。
- 范围：工艺 gate 缺失时先补足必要判断；失败时交付修改条件，不输出已通过的设计系列。
- 验收：系列内风格连贯、系列间差异明确；每个系列符合材料、工艺和原创性限制。


Require a manufacturing gate result. If it failed, return the required redesign instead of families.

## Procedure

1. Expand elements by role and visual treatment, not as a combinatorial catalog.
2. Build limited typography roles and stress-test content lengths and characters.
3. Build a material- and process-honest color system.
4. Select placements from real surface zones; fix placements that are risky as buyer choices.
5. Select compositions from product geometry, reading distance, text length, and process constraints.
6. Build Style Compatibility rows before families.
7. Create up to four Design Families, each with one buyer, occasion, emotional promise, market position, style anchor, narrative, motif language, type, color, composition, placement, negative space, material, processes, personalization strategy, allowed/forbidden elements, restrictions, files, tests, and do/don't rules.
8. Audit semantic coherence, style coherence, hierarchy, Gestalt, balance, negative space, proportion/scale/rhythm, type, color, material honesty, function, personalization usability, and commercial feasibility.

Families must be visibly related within and meaningfully different between. Reject style soup and any family that depends on a process translation not planned in its production requirements.

完成本轮所需交付及上述验收后结束。内部必要依赖可以继续；不自动追加下一项业务或要求用户重新调用同一任务。
