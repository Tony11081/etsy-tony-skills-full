# 审查规则与评分

来源 ID 对应 [官方来源索引](official-sources.md)。下列摘要只帮助定位核查，重大结论需读取现行正文。

## 1. 商品资格、真实披露与 IP

| 核查项 | 判断方式 | 来源 |
| --- | --- | --- |
| 允许销售资格 | 查实际设计、制作、采购和定制流程，匹配 Made / Designed / Handpicked / Sourced。采购不自动等于违规；符合条件的供应品等有不同规则。来源不明则待确认。 | S1 |
| Vintage | 需有至少 20 年历史的事实依据；复古外观不能证明年代。 | S1 |
| AI 商品 | 确认商品创作是否使用 AI，再按适用条款披露；不能仅凭图片风格判定。区分商品创作和照片处理。 | S1 |
| 生产合作方 | 核实谁设计、谁生产及实际发货地；合作方与普通材料供应商不同，不能对所有非手作商品一律要求填合作方。 | S10 |
| 禁售/限制 | 按实际商品特征查当前禁售条款及例外；医疗效果、武器、危险品、受保护动植物等仅在相关时深入。 | S3 |
| IP | 查名称、图案、角色、标志、照片来源及适用授权。区分具体风险线索和法律定论；商标词出现不自动等于侵权，没出现也不代表安全。不能承诺“改几个字就安全”。 | S4 |
| 表述与履约 | 商品规格、包含项、制作分工、可选配置、价格和发货信息一致；不因无证据就指控造假。 | S5 |

## 2. 图片分支

先确定商品归属，再引用 S1/S2 对应规则。原照片的视觉真实性和照片使用权是两项不同证据。

- 通常使用实际成品的原创照片；卖家自行拍摄或受托拍摄均应准确呈现商品。
- 买家个性化商品：首图展示已完成定制的样例，不是空白品或占位文字 mockup；附图可按政策展示定制 mockup。
- 原创独特实物由合作方制造：核查实物成品照片要求。
- 原创图案印在基础商品上、由合作方生产：政策允许适用的 mockup；买家个性化商品仍按上一分支处理。
- 合格 Sourced 商品的商业图片按 S1 的专门规定及图片权利核查。数字商品按实际交付物展示，不要求不存在的实体照片。
- 评论买家照片需要相应许可。AI 修图或背景替换不能自动证明图片合规，更不能改变买家会收到的商品。

图片/CRO 建议选择有实际用途的图位：主图辨识、细节、尺寸参照、变体、包含项、定制步骤、实际使用、包装。不要为了固定张数凑图；仅看过 2 张图就只声称检查了 2 张。

## 3. 搜索表达

| 性质 | 可采用的规则 | 不应推导的结论 |
| --- | --- | --- |
| 官方字段限制 S6 | 标题最多 140 字符 | 必须填满 140 字符 |
| 官方建议 S8 | 简短清楚，重要客观差异前置，考虑少于 15 个词；场合/受众只在构成商品本质时放标题 | 15 个词及以上就是违规；更改标题必然提升销量 |
| 官方字段限制 S7 | 每条最多 13 个标签，各最多 20 字符；字母、数字、空格及允许的撇号/连字符，后两者不放开头 | 少用一个标签就不能发布 |
| 本 Skill 交付约定 | 一组完整建议恰好 13 个不重复英文短语，用英文逗号分隔 | 用未经证实的材质/用途补满 13 个 |
| 官方建议 S9 | 多词短语、准确具体、利用类目/属性、减少冗余、描述自然融入关键词 | 单词不得跨标签重复；第一标签享有额外权重；关键词位置决定排名 |

挑一个准确商品主短语和少量有事实支持的补充搜索意图。记录是模型建议、实际搜索词还是工具数据；没有需求数据时不报搜索量、竞争度或流量增幅。类目和属性不可见时可建议核查候选，但不能声称当前设置错误。英文稿用于英文 listing 或英文翻译字段，不建议在其他语言的主字段里随意混语种。

## 4. 购买信息与经营判断

- 让买家知道买到什么、数量/尺寸、如何选择及定制；道具不等于包含项，最低价不等于图片配置价。
- 报价记录所选变体、币种、目的地和获取时间；运费因地址变化时保留条件，不擅自补零。
- 查看处理时间、预计送达和退换条款是否清楚一致。数字/定制商品也不能凭类别就宣布“任何地区均不可退”。
- 面向美国的跨境订单，核对 S5 现行 DDP 要求；本次读取的政策不允许通过 DDU 等方式让买家购买后承担额外费用。不能沿用“关税一律由买家承担”的旧模板，也不能仅凭政策要求就断言卖家已采用 DDP；承运方案未确认则列为待核实。
- 看评论只归纳实际样本内的问题，不把评论总数当订单数。平台徽章不等于材质、原创性或合规证明。
- 经营效果分析使用同周期、同渠道、同粒度数据及明确分母。没有曝光无法计算点击率；不能用 visits 代替所有点击，不能把没有订单归因于单一文案问题。
- 已有表现良好的 listing，优先小范围有证据的改动。建议记录旧值和观察窗，区分季节、价格、广告和库存变化；不自动创建提醒或改广告预算。

### 4.1 固定检查项

完整商品审查和店铺审查都逐条检查下列 5 项，每项给出“发现 / 未发现 / 不可见”，不能跳过。优先级是默认值，按证据强弱调整。

| 检查项 | 怎么查 | 默认优先级与性质 | 来源 |
| --- | --- | --- | --- |
| 低价变体拉低展示价 | 对比搜索卡片/店铺首页显示的“起价”和主图所示配置的实际价格。若最低价来自与主图商品不同的选项（如实体商品里挂一个电子文件/样品/单件配件选项），记录两个价格和选项名。 | P0（与主图明显不是同一商品时）或 P1；`官方要求`：S5 要求真实呈现商品，S11 禁止为触发平台自动信号而操纵定价 | S5、S11 |
| 长期折扣 / 原价不真实 | 看是否有划线价和折扣比例；结合 listing 上架时间和销量判断原价是否“曾以该价在相当长时间内真实售出”。新上架就长期挂大折扣、或几乎一直在打折，视为风险。公开页看不到折扣历史时写“不可见”，请卖家确认。 | P1；`官方要求`/`官方建议`：S11 要求折扣是相对真实常规价的临时降价，长期打折的折后价可能在法律上被视为真实价格 | S11 |
| 同款重复 listing | 在已读取的店铺页内，查同一商品（同图、同款式、仅标题或标签不同）是否有多个 listing。每个 listing 的标题、标签、主图、目标人群确实不同时可以保留；几乎一样时建议合并或改成真正不同的定位。 | P2；`运营假设`：店内互相争抢同一搜索位、分散评价和收藏。本次未找到将其定为违规的 Etsy 官方条款，不要写成违规 | — |
| 数量上限 | 查可购买数量是否远低于该品类的常见单笔用量（如婚礼桌号、座位卡一单常需几十件）。数量不可见时写“不可见”。 | P2；`运营假设`：上限太低会直接挡住大单 | — |
| 欧盟 GPSR 信息 | 店铺若向欧洲经济区（EEA）或北爱尔兰买家销售，查 listing 是否填写 Manufacturers（制造商）与 Product safety info（产品安全信息），以及是否已添加欧盟境内的经济经营者。公开页通常看不到后台字段，看不到就写“不可见，请在后台核对”；店铺不向 EEA 销售时记 N/A。 | P1；`官方要求`：S12 | S12 |

这些项只基于实际读取到的页面得出结论；“看不到”不等于“没设置”。

## 5. 透明评分：内部内容检查，不是 Etsy 分数

完整商品审查默认给 SEO 内容分、购买信息/CRO 分。评分依据是“原页面”，不要把本轮新草稿的优点算入原页面。单字段任务、仅店铺首页审查无需评分。

每项 0–4 分：0 = 有证据表明缺失/严重冲突；1 = 重大问题；2 = 部分清楚但有实质缺口；3 = 基本清楚、有小问题；4 = 相关信息清楚一致。无法观察记 `U`，不适用记 `N/A`，两者均不是 0。每项用一句证据解释，避免仅报总分。

| SEO 项（各 4 分） | CRO 项（各 4 分） |
| --- | --- |
| 商品名称与搜索意图清楚 | 主图与所售商品/配置一致 |
| 标题准确、易读、重点清楚 | 包含项、规格、尺度清楚 |
| 原描述的事实与自然关键词 | 变体/个性化/数字交付流程清楚 |
| 原标签的准确性与意图覆盖 | 价格、配送条件和时间清楚 |
| 原类目与属性的准确匹配 | 细节证据、退换与必要披露清楚 |

计算：`内容分 = 已观察项得分之和 ÷ (4 × 已观察项数量) × 100`，四舍五入到整数。覆盖率 = 已观察项数量 ÷ 适用项数量；适用项包含 U，排除 N/A。少于 3 项可评分时不报总分，只列证据和缺口。覆盖不足 100% 时标“局部评分，不与完整分直接比较”。

例：SEO 五项为 3、2、4、U、U，则 9/12 = 75/100，覆盖 3/5 = 60%。不能把它报成无条件的 75 分，也不能报成 45 分。若全部 N/A 或未知，则不计算百分比。

合规风险独立报告，不计入平均分；高 SEO/CRO 分不能抵消 P0 风险。任何分数都不是排名、销量、转化概率或法律合规保证。
