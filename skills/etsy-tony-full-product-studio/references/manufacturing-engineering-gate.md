# Manufacturing Engineering Gate

This gate is mandatory before Design Families and recommended SKUs.

## 1. Product production structure

Record part count, each material, geometry, rigidity/flexibility, processable areas, functional zones, coatings/plating/paint/film, disassembly/reassembly, front/back, left/right, paired parts, food/skin contact, washing, cleaning, and outdoor exposure. Missing physical facts become Unknown — Physical Sample Required.

## 2. Process layers

- Primary Process: creates the main structure, graphic, or text.
- Secondary Process: supports the primary work.
- Finishing: cleaning, polishing, coating, film removal, curing, trimming, or edge treatment.
- Assembly: adhesive, screws, stitching, press fit, hardware, or other joining.
- Packaging: scratch film, sleeve, rigid support, bag, box, moisture protection, or instructions.

## 3. Expressive capability checklist

Minimum Line Width; Minimum Gap; Minimum Text Size; Stroke Continuity; Small Closed Areas; Negative Space; Detail Density; Color Count; Gradient; Halftone; Surface Contrast; Reflection; Curved Distortion; Registration; Edge Distance; Heat Sensitivity; Wash; Scratch; Outdoor; Food Contact; Skin Contact.

Use numeric values only from a dated production profile. Otherwise state Machine Parameter Not Confirmed and Sample Validation Required.

## 4. Cost and time direction

Assess Setup Time, Machine Time, Manual Labor, Color/Tool Changes, Steps, Waste, Failure Risk, Rework, Inspection, Packaging, Lead Time, Unit Cost Direction, and batch suitability using only Low, Medium, High, Requires Cost Input, or Requires Time Study.

## 5. Gate outcomes

- PASS TO DESIGN: credible material/process/zone path; untested parameters clearly constrained.
- CONDITIONAL PASS: design can continue only within specified translations; concepts may be Recommended for Sampling, but are not Listing-Ready and cannot receive production approval.
- FAIL / REQUIRES REDESIGN: one or more veto conditions block recommended SKUs.

## Development readiness

- Concept Candidate: evidence and concept structure exist, but no recommendation to spend sample resources has passed.
- Recommended for Sampling: customer/design/originality screens pass and the gate is PASS or CONDITIONAL; physical validation remains open.
- Listing-Ready: sample-backed product facts, materials/process, files, options, images, copy, QC, current platform rules, and consistency all pass. This does not mean published.
- Approved for Production: the exact tested material/process/file scope has Sample Passed evidence and manager release.

CONDITIONAL PASS can reach only Recommended for Sampling. Scores never override this ceiling.

## 7. Veto conditions

Veto when the main visual language cannot be reproduced; detail or type exceeds known ability; placement harms function; material/process conflicts; safety is unresolved; customization causes likely errors; excessive manual rework is required; production files cannot be made; production is claimed without samples; price band is implausible; or real output will likely diverge from the render.

For a valuable but blocked concept return Requires Redesign for Manufacturing and give a concrete translation path.
