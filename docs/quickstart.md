# 第一次使用：先交付一个具体结果

1. 安装后新开对话，输入 `$etsy-tony-full`，说明当前想完成的结果。
2. 提供你已有的商品文字、原图或公开链接。已经提供过的材料无需重复发送。
3. 先完成一项工作：例如只改一个标题，或用一张真实产品图生成一张新场景。
4. 查看实际成品，指出具体需要修改的地方。工具会保留其他条件，只调整你指定的部分。

可复制的第一个任务：

```text
$etsy-tony-full-title 我的商品是定制婚礼桌号牌，实际材料是透明亚克力，可定制桌号。
请写一个自然的英文 Etsy 标题，不添加我没有提供的尺寸、发货或性能承诺。
```

接着提供真实图片并说：

```text
$etsy-tony-full-photo-engine 用这张真实产品图生成一张婚礼桌面场景图。
保持牌子形状、文字、颜色和底座不变，道具不要让买家误以为包含在商品里。
```

图片默认需要宿主实际可用的内置图片工具；出现工具不可用时先保留计划和输入，不把提示词说成已经出图。缺商品事实只影响对应内容，文案不会偷偷补造材质或交期。

需要完整图组就调用 `$etsy-tony-full-photo-15`。需要开发新产品就调用 `$etsy-tony-full-original-product` 或 `$etsy-tony-full-design-skus`。制作既有产品场景与开发新款是不同任务，入口会按你要的成品选择。
