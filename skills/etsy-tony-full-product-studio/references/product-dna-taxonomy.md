# Product and Design DNA Taxonomy

## Core entities

- Product: the physical object purchased and used.
- Product Form: geometry, silhouette, proportions, components, and interface.
- Design Element: what appears.
- Element Style: how it appears.
- Placement: where it appears.
- Production Process: how it is made.
- Design Family: a coherent product line system.
- Base SKU: a stable internal production identity.
- Customer Selectable Option: a bounded buyer choice.
- Personalization Input: buyer-provided content.
- Add-on: extra paid work/material.
- Separate SKU: a production identity change.
- Separate Listing: a buyer/market/selection logic change.

## Competitor DNA fields

Product Form; Material; Finish; Main Motif; Secondary Motif; Decorative Motif; Typography; Text Hierarchy; Color System; Placement; Composition; Negative Space; Personalization Method; likely Production Process; Target Customer; Emotional Promise; Market Positioning; Main Visual Hook; Main Purchase Reason.

## Expression classification

- Category Convention: necessary or widespread form/function, such as a cake server blade and handle.
- Generic Design Language: broad unowned visual grammar, such as minimal line art or Art Deco symmetry.
- Competitor-specific Expression: the seller’s particular arrangement, motif treatment, copy, pairing, or look.
- Potentially Protected Expression: brand, logo, character, distinctive artwork, named franchise, recognizable composition, or protected text.

The first two may inform a new brief. The latter two belong in must-not-copy until independently cleared.

## Element roles

Classify each as Main Motif, Secondary Motif, Decorative Motif, informational text, personalization, frame/border, symbol/icon, background texture, repeat pattern, or negative-space device. For each record function, changeability, theme impact, style translations, process fit, and IP risk.

## Decision examples

- “Blade center” is Placement.
- “Laser Engraving” is Production Process.
- “Olive branch” is Design Element.
- “Vintage botanical engraving” is Element Style/Graphic Style.
- “Couple Names” is Personalization Input.
- “Gold-tone base” may be Finish or Separate SKU; it is not automatically a Color option.
