# Typography Framework

## Roles

Define Display Font, Name Font, Date Font, and Supporting Font only when each has a distinct job. Prefer one or two families; a third requires a functional reason.

Record classification (Serif/Sans/Script), weight, contrast, letter spacing, line spacing, case, readability, personality, historical style, and process suitability.

Useful directions include Modern, Classic, High-Contrast, Old-Style, Condensed or Editorial Serif; Geometric, Humanist or Condensed Sans; Handwritten, Signature, Formal or Casual Script; Brush, Vintage Sign Painting, Western, Art Deco, Victorian, Retro, Groovy, Typewriter, Blackletter, and Minimal Typography.

## Stress tests

Test:

- 4-character name
- 10-character name
- 15-character name
- two names with separator
- surname/family name
- date in allowed formats
- uppercase and lowercase
- multiline content
- every required language character, punctuation mark, apostrophe, hyphen, and accent

Record fit, readability, hierarchy, required fallback, and proof need. Do not invent a character limit from a mockup; derive it from confirmed artwork area and sample results.

## Customer-facing fonts

Use simple labels such as Elegant Script, Classic Serif, Modern Minimal, and Casual Handwritten. Store the real licensed internal font name separately. Never expose all installed fonts.

For each F-code record best use, prohibited use, length guidance, case guidance, process limit, license status, and fallback.

## Process rules

- Laser/etching: avoid unsupported hairlines, counters, or small calligraphy; sample minimum size.
- Embroidery/chain stitch: Digitization Required; test counters, joins, stitch direction, pull compensation, and long-name scaling.
- Printing: test contrast, ink spread, white underbase, and small reversed type.
- Cutting/emboss/deboss: check bridges, minimum connections, depth, and fill.

Typography is part of production, not a decorative afterthought.
