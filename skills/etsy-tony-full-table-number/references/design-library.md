# 按需使用的设计参考库

这些是历史探索中有用的设计方向，不是确认的材料供应、制造方案、字体文件或用户最终选择。允许提出新方向，不要求每轮都覆盖。

## 字体

| 方向 | 可见特征 | 对比关注 |
|---|---|---|
| 古典罗马／旧式衬线 | 适中粗细对比、有过渡的衬线 | 端庄与可读性；旧式数字高低不同需检查整套排列 |
| 高对比衬线 | 竖向粗笔画、细衬线 | 精致但镜面亮处细线可能消失 |
| 纤长时装体 | 窄长比例 | 与普通高对比衬线应有实质比例差别，勿挤压字体假造 |
| 浪漫斜体 | 倾斜、弧形收笔 | 不等于任意倾斜正体；保持两位数左右留白 |
| 手写书法 | 笔势、粗细变化、克制尾笔 | 与普通斜体拉开差异；避免难辨和跨入边框的花笔 |
| 装饰艺术体 | 几何、阶梯或双线细节 | 避免重复线条使 1 看成 11 |
| 柔圆复古衬线 | 饱满、圆润收笔 | 别变成卡通泡泡字 |
| 简洁无衬线 | 开放、清晰 | 可用中等字重；细线不是默认更高级 |

字体对比固定材质、文字颜色、视觉高度、位置与场景。样张优先用同一个两位数。未找到真实字体时只称“字形方向”，不标造假的品牌字体名称。

## 材质与配色组合

| 底材方向 | 字色／字材候选 | 视觉目的 |
|---|---|---|
| 象牙白厚卡纸、纹理纸、棉纸 | 深咖、深棕、深古铜 | 柔和、清晰；纸纹不要夸大 |
| 香槟金镜面亚克力 | 深咖平面字、象牙白立体字 | 反光与哑光对比；浅字需环境验证 |
| 烟灰镜面亚克力 | 象牙白字 | 轻盈与明暗层次；保留镜面而非变成灰色实心板 |
| 午夜蓝、炭黑哑光板 | 奶油白、缎金、拉丝金属感字 | 较强颜色对比 |
| 酒红、梅紫、灰粉 | 奶油白、深梅紫、金色或银镜字 | 正式或浪漫，避免所有红紫色都渲成相同色 |
| 鼠尾草绿、橄榄绿、灰蓝绿 | 墨绿、象牙白、磨砂字 | 自然或现代；低对比方案应标记 |
| 珍珠白板、白色涂装木板 | 深古铜、深咖 | 珠光与木纹只是拟议表面，不推断基材 |
| 亚麻、绒面、皮纹 | 橄榄绿刺绣、缎金贴字、深咖压凹 | 硬软材料对比；皮纹不等于确认真皮 |
| 浅蓝纸、暖灰板 | 铜色箔、深咖双层金边 | 冷暖与边缘层次 |

## 文字工艺：表现与边界

| 工艺方向 | 图中应体现 | 不能偷换为 |
|---|---|---|
| 哑光平面印字 | 平整、不透明、无明显凸起 | 厚贴字或金属反光 |
| 箔压印 | 局部金属光泽、可有轻微压痕 | 粗糙金粉、厚金属板 |
| 棉纸压凹／皮纹压印 | 浅凹边缘、对应底材纹理 | 切穿的空洞或深槽 |
| 雕刻填色 | 有限凹深及填色 | 双层镂空夹板；也不把任意镜面板默认视为可用 |
| 局部亮光 | 薄透明涂层的方向性高光 | 厚塑料立体字 |
| 亚克力、木材、金属立体字 | 对应表面、边缘、紧贴投影 | 夸张挤出、漂浮字、把金属色当真金属 |
| 磨砂半透明字 | 柔和透光、背景颜色影响字边 | 自发光或内置 LED |
| 刺绣 | 连贯针迹、底布织纹 | 普通印刷纹理；细字不能凭图保证可绣 |
| 珍珠镶嵌 | 珠粒排列、承载字形 | 无支撑漂浮珠或夸大宝石价值 |
| 金属轮廓字 | 空心字形、细轮廓与小投影 | 实心填金或过度花线 |
| 陶瓷釉感字 | 圆润边缘、釉面光泽 | 已确认陶瓷工艺或耐久性 |
| 双层金边字 | 对齐叠层、窄金边 | 无意偏移的投影字 |

局部放大必须对应整图同一数字、底色与结构。提出跨材质工艺时标注是外观目标，兼容性待供应商验证。
