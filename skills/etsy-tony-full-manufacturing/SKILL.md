# Etsy Manufacturing Gate

## 当前任务与交付

- 材料：产品图、结构或材料说明，以及当前可用的设备资料、供应商限制或样品记录。
- 范围：只评估本次材料和工艺路径；未提供机器参数或测试记录时保留未知。
- 验收：输出工艺结论、允许与禁止的设计范围及必要测试；无实物证据不得批准生产。


Production precedes aesthetic recommendation.

## Procedure

1. Map components, joins, orientation, pairs, food/skin contact, washing, cleaning, and outdoor exposure.
2. For every surface zone, record geometry, function, wear, visibility, fixture need, artwork/text suitability, and process access.
3. Separate Primary, Secondary, Finishing, Assembly, and Packaging processes.
4. Build Material–Process rows using only Recommended, Conditionally Available, Sample Test Required, Not Recommended, or Unknown.
5. Build Process–Style rows using only Compatible, Conditionally Compatible, Requires Translation, Sample Test Required, or Not Recommended.
6. Check line/gap/text/detail/color/gradient/halftone/contrast/curvature/registration/edge/heat/wash/scratch/outdoor/contact constraints. Use numbers only from a dated production profile or test record.
7. Map required production files and preparation: vectorization, digitization, outline expansion, separations, halftone, cut paths, bleed, safe area, mirror, reverse work, white ink, varnish, or registration.
8. Select relevant sample tests and QC points.

## Gate

Return PASS TO DESIGN, CONDITIONAL PASS, or FAIL / REQUIRES REDESIGN. State allowed and prohibited design languages.

Reject a design path if the process cannot express its main language, text is unreadable, the zone harms function, material compatibility is absent, safety is unresolved, option error risk is high, rework is excessive, production files cannot be made, price-band fit is implausible, or render and physical result would diverge.

Without physical evidence, Production Approval is Concept Only, Awaiting Machine Parameters, or Sample Required. Never mark Approved for Production.

完成本轮所需交付及上述验收后结束。内部必要依赖可以继续；不自动追加下一项业务或要求用户重新调用同一任务。
