# Production File Requirements

Mockups and listing images are not production files.

## Process mapping

| Process | Candidate files | Required preparation |
|---|---|---|
| Laser engraving/marking | SVG, AI, PDF, high-resolution PNG when raster is validated | vectorization, outline conversion, black/white or tested grayscale, origin/orientation, scale, safe area |
| Laser cutting | SVG, DXF, AI, PDF | closed paths, cut/score layers, kerf allowance from test, bridges, holes, nesting |
| Embroidery | DST, PES, EMB, EXP as equipment/software requires | Digitization Required, stitch path/direction, underlay, density, pull compensation, trims, color sequence |
| DTF/DTG/Sublimation | transparent high-resolution PNG or print-ready file | correct dimensions, transparency/white base, color profile, mirror for applicable transfer, bleed/safe area |
| Screen printing | AI, PDF, SVG or separated raster | color separation, trapping, underbase, halftone, registration marks |
| UV printing | print-ready PDF/TIFF/PNG/vector per RIP | white ink layer, varnish layer, front/reverse order, cut path, registration, bleed |
| Emboss/Deboss | AI, SVG, PDF, tooling drawing | positive/negative die logic, depth/tooling limits, outline expansion |
| Etching | vector or high-resolution mask file | resist/mask separation, scale, safe edge, orientation |

## File release record

Every production file package includes SKU code, P/F/C/L/S/M/FN codes, file version, confirmed physical size, orientation, process, machine profile, material/finish, color sequence, layer legend, fonts outlined/expanded as required, linked assets embedded, proof image, operator notes, and approval state.

Use “Machine Profile Required” until a real profile is linked. Never name an unsupported format as production-ready merely because it can be exported.
