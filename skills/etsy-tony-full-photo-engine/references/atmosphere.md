# 氛围：让买家看一眼就想要

买家买的不是一只袜子，是「平安夜全家的袜子按名字挂成一排，树灯亮着」那一幕。主图和场景图的任务是把那一幕拍出来。产品画得再准，那一幕没出现，这张图就只是一张证明图，不会让人想买。

实测的失败样子（丝绒圣诞袜，15 张）：十二张是同一面灰墙，角上一枝松枝，平光，袜子空着贴在墙上。保真、色彩、构图代号都过了，但遮住袜子，没人看得出这是圣诞。原因不在模型，在规则：保真、色准、道具从简都有硬门，氛围没有下限，于是每一步都往「干净」退，退到最后就是目录图。

这一份给氛围定下限。它和保真、色准、尺度并列，同样是硬门。

## 1. 先判这件产品靠什么卖：`atmosphere.type`

| 类型 | 是什么 | 例子 |
| --- | --- | --- |
| `occasion_led` 场合型 | 离开那个场合就卖不动。买家是在为一个日子做准备 | 圣诞、万圣、感恩节、复活节用品；婚礼用品；新生儿和迎婴；生日、毕业、母亲节父亲节、纪念日、乔迁礼物 |
| `lifestyle_led` 生活型 | 卖的是「用上它的日子」 | 家居装饰、厨房餐桌、首饰、服装、包袋、宠物用品、蜡烛香氛 |
| `proof_led` 证据型 | 买家要确认的是规格和兼容 | 工具、配件、材料、数字产品 |

定制礼品几乎都是场合型：先问「她为哪一天买的」。一件产品同时沾两类时取前面的。

## 2. 写下那一幕：`atmosphere`

存进 `art_direction`：

```json
"atmosphere": {
  "type": "occasion_led",
  "the_moment": "平安夜，孩子睡了，袜子按名字在壁炉台上挂成一排，树灯亮着，礼物刚摆到树下",
  "feeling": "期待，团圆",
  "signals": ["亮着灯的圣诞树", "壁炉台上的雪松花环和小灯串", "牛皮纸包的礼物", "一排家人的袜子", "窗外的雪或暮色", "一杯热可可", "袜口露出的糖果手杖和小礼物"],
  "glow": ["背景的树灯", "花环里的小灯串", "远处一支蜡烛"],
  "life_trace": ["往袜子里塞礼物的手", "够袜子的小手", "喝了一半的热可可", "拆到一半的包装纸"],
  "product_state": ["装满", "和家人的袜子挂成一排", "刚被挂上"]
}
```

- `the_moment` 一句话，有时间、有人（可以不入画）、有正在发生的事。「袜子挂在墙上」不是一幕。
- `feeling` 一两个词，后面每张场景图都要让人感到它。
- `signals` 列六到八样**具体的东西**，从 [scene-library.md](scene-library.md) 的家族条目和场合层里取，再按产品补。写「圣诞装饰」不算，写「亮着灯的圣诞树」才算。
- `glow` 场合本身有光的（节日、烛光晚餐、生日蜡烛、秋冬傍晚），列出发光的东西。它们是氛围最大的来源。
- `life_trace` 人来过或正在场的证据。
- `product_state` 产品在那一幕里的样子：用着的、装着的、戴着的、成套的。空着摆着只留给证据图。

## 3. 场景四级，按渲染结果判

| 级 | 名字 | 画面里有什么 |
| --- | --- | --- |
| `L0` | 纯底 | 无缝背景、白底、渐变 |
| `L1` | 点缀 | 一面墙或一块台面，加一两件小道具。认不出是家里的哪里 |
| `L2` | 一角 | 认得出的地方（壁炉台、楼梯口、玄关、餐桌、床头），至少两层空间，至少两样 `signals` |
| `L3` | 那一幕 | 前、中、后三层；至少三样 `signals`，分在不同的层；场合有光的，背景里至少一处 `glow`；一处 `life_trace`；产品处在 `product_state` 里的一种状态 |

**一面墙加一枝松枝是 `L1`，算证据图，不算场景图。** 计划里每张图标 `scene_level`，审图时按实际画面重判。

下限（15 张一套，其他张数按比例）：

| 类型 | 主图 | `L3` 至少 | `L2` 和 `L3` 合计至少 | `L0` 和 `L1` 最多 |
| --- | --- | ---: | ---: | ---: |
| `occasion_led` | `L3` | 5 | 9 | 6 |
| `lifestyle_led` | `L2` 或 `L3` | 3 | 7 | 8 |
| `proof_led` | 不限 | 0 | 有真实使用情境时 3 | 不限 |

- 场合型的前三张里至少两张 `L3`。买家多数只看前三张。
- `L0`、`L1` 留给必须隔离的证据：名字特写、材质微距、尺寸、选项、背面。
- 单张图的任务：主图和生活图按上表的主图一档做。

## 4. 氛围从哪来

按效果排序。一张 `L3` 至少用到前四样。

1. **光有深浅。** 一个说得出来源的主光从侧面打亮产品，背景比产品暗半档到一档，暗处有发光的点（树灯、灯串、烛火虚成的光斑）。一样亮的灰墙没有氛围，无论加多少道具。
2. **画面有前后。** 前景一点虚掉的东西（枝叶、礼物一角、丝带、杯沿），中间是清楚的产品，后面是交代地点和场合的环境。
3. **场合认得出。** 三到五样 `signals`，一样在前景、一两样在产品旁、其余在背景。
4. **有事正在发生。** 一处 `life_trace`：一只手、半杯喝的、拆了一半的包装。
5. **产品在用。** 袜子是装满的，项链是戴着的，砧板上有切了一半的面包，蜡烛是点着的。
6. **世界是买家想要的家。** 风格按 `buyer_reading.taste`，向往但够得着。

氛围不是堆东西，也不是加黄：

- `signals` 多数放在背景和前景并虚化。产品周围一圈保持干净，产品仍是画面里最清楚、颜色最浓的东西。
- 暖只来自 `glow` 里的光源；打在产品上的光是中性的，白还是白（15 图 Skill 的 scene-planning 第 3 节）。
- 场合本身是暖的（圣诞与冬季节日、秋季、烛光餐桌、壁炉边），主图和场景图的 `mood_profile` 用 `warm_scene`，这是默认，不需要另找理由；改用 `true_color` 才需要写理由。证据图照旧 `true_color`。
- 尺度照 [scale-realism.md](scale-realism.md)：`L3` 不等于拍整个房间。镜头可以很近，背景虚成光斑和色块，一样是 `L3`。

## 5. 验收：`atmosphere_check`

每张 `L2`、`L3` 的图过三问，各写 pass 或 fail 加一句画面里看得见的证据：

| 项 | 怎么验 |
| --- | --- |
| `cover_test` | 遮住产品只看其余部分。一秒内说得出是什么场合、什么时刻吗？说不出就是 fail |
| `hero_test` | 反过来，只看产品。它还是最清楚、最亮、颜色最浓的东西吗？场景抢了戏就是 fail |
| `desire` | 买家想走进这个画面吗？对着 `the_moment` 和 `feeling` 看：那一幕出现了吗？感受得到那个词吗？ |

再按第 3 节重判 `scene_level`。达不到计划的级别就重做。整套审完数一遍，不够下限就把最弱的 `L1` 换成 `L2` 或 `L3`。

主图另加一条：和 Etsy 上同类热卖品的主图并排看。它们多数是完整的一幕；我们的是一面墙，就输在第一眼。手头没有竞品主图时记 `unverified`。

## 6. 「没氛围」的六个原因和改法

| 看到的 | 原因 | 改法 |
| --- | --- | --- |
| 灰墙或白墙加一枝松枝 | 只做到 `L1` | 换成认得出的地方，加背景和前景，按 `L3` 写 |
| 每样东西一样亮，没有影子 | 平光 | 侧光打产品，背景压暗半档到一档，暗处放光斑 |
| 干净但冷，像目录 | 场合是暖的，却用了 `true_color`，或者怕偏色把暖全删了 | 主图和场景图改 `warm_scene`，暖放在背景光源上 |
| 产品空着、孤零零 | 没有 `product_state` 和 `life_trace` | 装满、成排、上身、有手 |
| 张张同一面墙 | 一个世界被理解成一个机位 | 同一个家的不同位置和时刻：壁炉、楼梯、玄关、树下、圣诞早晨 |
| 为了保真不敢写场景 | 把主图当成了保真探针 | 保真探针用一张证据图做；主图按 `L3` 做，它是氛围探针 |

## 7. 各场合的氛围清单

写 `atmosphere` 时从这里起步，按产品增删。

| 场合 | 那一幕 | 信号 | 光 | 人的痕迹 |
| --- | --- | --- | --- | --- |
| 圣诞与冬季节日 | 平安夜的客厅；圣诞早晨的树下 | 亮灯的树、花环和灯串、包好的礼物、成排的袜子、窗外的雪、热可可、糖果手杖 | 傍晚侧窗光；背景树灯和灯串成光斑；烛火 | 塞礼物的手、孩子的小手、拆开的包装纸 |
| 万圣节 | 天黑前的门廊；糖果碗边 | 雕好的南瓜、干枝、蜘蛛网、糖果碗、门廊台阶 | 暮色；南瓜灯和蜡烛的光 | 伸向糖果的小手、戏服的一角 |
| 秋季、感恩节 | 开饭前的长桌 | 小南瓜、干叶、格纹毯、烤好的派、成套的餐具 | 午后低角度的窗光；桌上的烛火 | 摆餐具的手、倒了一半的酒 |
| 情人节、周年 | 清晨床边的礼物；晚餐桌 | 手写卡、一两枝花、丝带、两只杯子 | 清晨柔光，或一支蜡烛 | 写了一半的卡片、牵着的手 |
| 母亲节、春季 | 早餐托盘端到床上 | 当季鲜花、茶、手写卡、托盘 | 明亮通透的上午窗光 | 孩子画的卡片、捧杯的手 |
| 婚礼 | 仪式前的准备；切蛋糕的一刻 | 真花、丝带、请柬、蛋糕、香槟杯、婚纱一角 | 高调日光；傍晚的串灯 | 新人的手、戒指、伴娘的裙摆 |
| 迎婴、新生儿 | 布置好的婴儿房；满月照 | 婴儿床、藤篮、小衣物、木玩具、绘本 | 上午柔光，白纱帘透进来 | 宝宝的小手小脚、妈妈的手 |
| 生日 | 吹蜡烛前 | 蛋糕和蜡烛、彩带、气球、包好的礼物 | 室内日光加烛光 | 围过来的手、拆礼物 |
| 毕业、父亲节 | 书桌前；出门前 | 证书、学位帽、手表、书、咖啡 | 稍硬的侧光 | 整理领带的手、握杯的手 |
| 乔迁 | 搬进来的第一周 | 钥匙、纸箱一角、绿植、靠墙没挂的画 | 明亮日光，空一点的房间 | 开箱的手、地上的工具 |
| 纪念、缅怀 | 安静的一角 | 一张照片、一枝花、一支蜡烛 | 柔和侧光，留白多 | 轻轻放下东西的手 |
| 宠物 | 玄关出门前；它的窝边 | 牵引绳、食盆、玩具、窝 | 日光 | 宠物本身入画（局部），主人的手 |
| 日常家居、厨房 | 周末的早晨；晚饭前 | 当季的花或水果、书、正在做的菜 | 窗边的自然光 | 半杯咖啡、切了一半的面包 |

生活型产品没有固定的节日，就选它最常被用上的那个时刻来写。
