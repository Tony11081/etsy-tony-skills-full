# Custom Options Matrix

Create rows for Pattern, Font, Color, Personalization, Placement, Size, Material, Finish, Process, Add-on, Packaging, and Gift Message even when Fixed or Not Offered. When applicable, add Production Configuration / Print Side and Component / Stand Color rows. Do not put front/reverse print into Placement.

| Field | Content |
|---|---|
| Option Name | Buyer-facing plain-language name |
| Option Type | Pattern / Font / Color / Personalization / Placement / Size / Material / Finish / Process / Production Configuration / Print Side / Component / Stand Color / Add-on / Packaging / Gift Message |
| Internal Code | P/F/C/L/S/M/FN or controlled field code |
| Available Values | Tested or conditional values |
| Default Value | One production-safe default |
| Customer Selectable | Yes / No / Conditional |
| Preview Required | Yes / No and reason |
| Proof Approval | Required / Recommended / Not Needed |
| Production Impact | Setup, file, labor, material, QA |
| Price Impact | None / Add-on / Separate price input |
| Lead Time Impact | None / Low / Medium / High / Requires Time Study |
| Compatibility Rules | Rule IDs |
| Invalid Combinations | Explicit exclusions |
| Separate SKU | Yes / No and trigger |
| Separate Listing | Yes / No and trigger |
| Reason | Buyer and operations rationale |
