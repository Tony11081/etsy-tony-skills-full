## 一条命令安装

需要 Node.js / npm，以及支持 Skills 的 AI 客户端。在终端运行：

```bash
npx -y skills add Tony11081/etsy-tony-skills-full -g --all
```

该命令向 Skills CLI 支持的客户端全局安装整包。只装到 Codex：

```bash
npx -y skills add Tony11081/etsy-tony-skills-full -g -a codex --skill '*' -y
```

安装后新开一次对话。无需记住 26 个名字，直接输入：

```text
$etsy-tony-full 我是新手，请根据我现有的商品资料，带我完成一项实际工作。
```

也可以对支持安装 Skill 的助手说：

```text
请从 https://github.com/Tony11081/etsy-tony-skills-full 安装全部 Skills，然后教我使用 $etsy-tony-full。
```

更新时重新执行安装命令；已安装目录内的个人修改请先备份。整包安装保证内部依赖齐全。本包使用独立的 `etsy-tony-full-*` 名称，可与旧版、[入门版](https://github.com/Tony11081/etsy-tony-skills) 共存。

## 直接复制这些用法

```text
$etsy-tony-full-title 根据这些已确认事实，写一个自然的英文 Etsy 标题，只给标题。

$etsy-tony-full-photo-15 根据我的真实产品图，制作 15 张独立场景图，保持产品和刻字不变。

$etsy-tony-full-original-product 参考这些公开竞品的买家需求，给我 3 个原创产品方向，先让我选款。

$etsy-tony-full-design-skus 先做 6 张独立概念图供我选择，再开发我选中的款式。

$etsy-tony-full-listing 这是商品事实和竞品链接，请做完整英文 Listing 草稿及 13 个标签，标明证据与未知项。

$etsy-tony-full-gigab2b-draft 为这个 GigaB2B 商品准备完整 Etsy 草稿。先交付本地资料，我指定店铺并授权后再保存后台。
```

## 使用前知道这几件事

- **Skills 免费，不代表模型、图片生成或会员服务免费。** 文案与分析可用宿主当前模型；出图默认需要 Codex 的内置图片工具。其他客户端须有对应工具，安装成功不能证明出图能力可用。
- eRank 会员研究使用自己的已登录账号或真实导出；基础写作不要求 eRank。Clawlist Gemini 仅在明确选用对应流程时需要自己的配置。见 [工具与配置](docs/setup.md)。
- 商品、成本、库存、尺寸、材质、交期和账号均来自使用者自己的已确认资料。没有附带作者的私人商品原图、店铺数据、登录状态或密钥。
- 默认研究、制作和草稿。进入店铺保存必须已有明确授权；发布、采购、支付、删除和账号变更不会因安装而获准。
- 模型图不是实物样品；历史知识库不是当前政策。当前平台规则要在执行时核对官方来源，未知事实保持未知。
