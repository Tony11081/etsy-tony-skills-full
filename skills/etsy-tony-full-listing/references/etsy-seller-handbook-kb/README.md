# Etsy Seller Handbook Reference Knowledge Base

This directory contains the portable Seller Handbook reference snapshot used by
`scripts/clawlist_optimize.py`.

- Snapshot: 2026-07-29
- Unique article records: 945
- Sources: Etsy's official All articles directory plus 11 official category indexes
- Database: `etsy_seller_handbook_kb.sqlite`
- SHA-256: `2289ee990d145abe5531f7540b5c172c4e60691f5e8873599ba31e8331ecb293`

The database stores titles, official index summaries, metadata, categories, Chinese
topic aliases, and official URLs. It does not contain full copyrighted article bodies.
Policy, legal, tax, fee, product-safety, and current platform claims still require a
live official-source check before seller action.
