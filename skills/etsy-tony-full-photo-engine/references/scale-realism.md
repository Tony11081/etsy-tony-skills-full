# 尺度真实：产品放进场景里，大小要对

生图模型有一个固定的毛病：为了让产品当主角，它会把产品画大，而不是把镜头推近。壁炉、门、楼梯这些环境照正常大小画，产品却大了一圈，画面就有说不出的违和感。

实测例子（48 cm 的丝绒圣诞袜，环境远景）：壁炉本身的尺寸是对的（台面离地约 137 cm，炉膛开口约 92 × 72 cm），袜子却被画成约 95 cm 长，从台面一直垂到炉膛地面，挡住半个炉膛。门板上那张大了约一半，楼梯边那张也大了六成以上。椅背上、手里拿着的那几张是对的。

规律很清楚：**参照物越大、镜头越远，产品越容易被放大。** 买家是照着图判断大小的，图里大一倍，收到货就是「比图上小很多」的差评。

所有带场景的图都过这一关。家具另见 photo-15 的 `furniture-scale.md`，可见人体另有 `human_scale_status`；这里管的是所有产品对所有场景。

## 1. 先锁尺寸：`scale_lock`

写任何场景之前，把产品的真实大小写进计划：

```json
"scale_lock": {
  "real_size_cm": { "long": 48, "short": 26, "note": "高度不含挂环", "source": "listing" },
  "size_class": "forearm",
  "body_relation": "全长约等于成人肘到指尖；袜口宽约两个手掌并排",
  "anchors": [
    { "name": "壁炉台面离地", "real_cm": [130, 140], "relation": "袜长约为台面高度的三分之一" },
    { "name": "炉膛开口宽", "real_cm": [80, 100], "relation": "袜子最宽处不到炉膛宽度的三分之一" }
  ],
  "placement": "挂在台面下沿，袜尖大约到炉膛开口的上沿，炉膛完整露出"
}
```

- `real_size_cm` 只用 listing、实测或用户给的数字，`source` 写清来源。没有可靠尺寸时写 `unverified`：这套图只拍没有尺度参照的画面（纯底、近景、平铺），并在交付时提醒补尺寸。不许猜一个数。
- `size_class` 按最长边分：

| 级别 | 最长边 | 例子 |
| --- | --- | --- |
| `palm` 掌心级 | 8 cm 以内 | 耳环、戒指、吊坠、钥匙扣 |
| `hand` 手级 | 8 到 20 cm | 马克杯、蜡烛、小摆件、卡包 |
| `forearm` 小臂级 | 20 到 50 cm | 圣诞袜、相框、抱枕、托特包、砧板 |
| `torso` 躯干级 | 50 到 100 cm | 毯子、挂毯、门垫、花环、大幅挂画 |
| `furniture` 家具级 | 100 cm 以上 | 见 furniture-scale.md |

- `body_relation` 用人体说一遍大小。模型对「一掌宽」「肘到指尖」比对厘米更有感觉。
- `anchors` 每个场景最多选两个参照物，各写一句产品与它的相对关系。参照物从下面的表里挑。
- `placement` 写产品落在哪里、垂到哪里、不挡住什么。这一句最管用。

## 2. 参照物：只用尺寸稳定的

**稳定，可以当参照（厘米）：**

| 参照物 | 尺寸 |
| --- | --- |
| 成人手 | 掌宽 8 到 9，手长 17 到 19，食指宽约 1.8 |
| 室内门 | 宽 76 到 86，高 200 到 210；门把手离地 90 到 105 |
| 壁炉 | 台面离地 130 到 140；炉膛开口宽 80 到 100、高 65 到 75 |
| 桌台 | 餐桌高 72 到 76；厨房台面高 86 到 92；茶几高 40 到 46；床头柜高 55 到 65 |
| 椅子 | 座高 43 到 48；椅背顶离地 85 到 100；椅背宽 40 到 48 |
| 沙发、床 | 沙发座高 40 到 46、座深 50 到 60；床面离地 50 到 65 |
| 楼梯 | 扶手高 86 到 96；栏杆间距 10 以内；踏步高 17 到 19 |
| 桌面小物 | 马克杯高 9 到 10、口径 8；餐盘直径 26 到 28；平装书 13 × 20；A4 纸 21 × 29.7；红酒瓶高 30；铅笔长 19 |
| 床品 | 标准枕头 50 × 70；抱枕 45 × 45 |
| 墙面 | 开关面板约 7 × 12；踢脚线高 8 到 15 |

**不稳定，不当参照：** 圣诞树、绿植、花瓶、礼盒、篮子、蜡烛、相框、地毯、松枝花环、装饰摆件、壁炉立柱的宽度。这些东西什么尺寸都有，模型会顺手把它们画小来迁就放大了的产品，看起来「合理」，其实整幅都错了。它们可以出现，但不能是画面里唯一能判断大小的东西。

## 3. 写场景时的七条

1. **想让产品大，就把镜头推近，裁掉环境。不放大产品。** 产品在画面里占多少由取景范围决定：

   `产品占画面的比例 ≈ 产品真实尺寸 ÷ 取景范围的真实尺寸`

   拍下整个壁炉（取景高约 150 cm），48 cm 的袜子只占画面高度的三分之一。想让它占到七成，取景就只有约 70 cm 高：台面下沿到炉膛上沿这一段，看不到地面。这两种都对；「整个壁炉入画、袜子还占七成」不存在。
2. **远景先算占比。** 环境远景（构图 `I`、`K`）写 prompt 前先按上式算一遍，把结果写进 prompt。产品占比低于画面的五分之一，缩略图里就看不清了：这件产品不适合这么远，退到「一面墙、一张桌、一个角落」为止。各级别最远能退到哪里见第 6 节。
3. **参照物和产品在同一纵深。** 同一面墙、同一张台面、同一只手里。一前一后时，近的显大、远的显小，量出来没有意义，看起来也怪。
4. **中长焦，平视产品。** 50 到 85 mm 的镜头感，机位在产品的高度。广角贴近拍会把靠镜头的东西撑大。
5. **服从重力和用法。** 挂着的东西垂直下垂，挂点在真能挂的地方；放着的东西有接触阴影；产品不挡住它旁边东西的功能（袜子不盖住炉膛，挂画不压到沙发靠背）。
6. **同框多件大小一致。** 同款几件一样大；成套里的大小关系按真实尺寸来。
7. **手和产品在一起。** 手握着或托着产品，不伸向镜头；手与产品的比例按 `body_relation`。

## 4. prompt 里的尺度句

放在画面段，紧跟「产品挂在或放在哪里」之后。三句：真实尺寸一句，相对关系一到两句，落点和取景一句。

```text
The stocking is an ordinary family-size Christmas stocking, 19 inches (48 cm) long. It hangs from a small hook under the mantel shelf and its toe ends about level with the top of the firebox opening, so the whole firebox stays visible below it. It is roughly a third as tall as the mantel is high. The camera stands far enough back to show the whole fireplace, so the stocking takes up about a third of the frame height.
```

- 同时给英寸和厘米；再给人体或家具的相对关系，模型主要靠后者。
- 环境镜头里不写 `large`、`big`、`oversized`、`prominent`、`fills the frame`、`hero`。想突出产品，写光、写颜色反差、写留白，不写大。
- 收尾段加一句针对性的排除：`Do not enlarge the stocking to make it stand out.`
- 近景和特写里没有参照物，不需要尺度句，写了反而多一个出错的地方。

## 5. 验收：`scale_status`

每张有稳定参照物的图都量一次，结果记在该图的 `scale_status`：

1. 在图上量两条像素长度：产品的长边，参照物上一条已知尺寸的边（两者要在同一纵深）。
2. 跑脚本：

   ```bash
   python scripts/scale_check.py --product-cm 48 --product-px 478 \
     --anchor "mantel height:130-140:680" --anchor "firebox width:80-100:460"
   ```

3. 按偏差判定：

| 偏差 | 判定 | 处理 |
| --- | --- | --- |
| 15% 以内 | `pass` | 通过 |
| 15% 到 30% | `borderline` | 只有非主图、且买家另有尺寸图可看时，经用户同意保留；否则重做 |
| 超过 30% | `reject` | 重做 |

没有稳定参照物的图记 `no_anchor`，不用量，但仍要过一眼测试：先遮住产品只看环境，再看产品，问一句「这东西拿在手里有多大」。答案和 `real_size_cm` 差得远就是 reject。

重做时只改尺度句和景别，其他不动。同一张连续两次还是偏大，说明这个景别模型画不对：换近一档，裁掉大的建筑参照，改用和产品同一量级的参照物（手、椅背、门把手、桌上的杯子）。

整套图里第一张环境图是**尺度探针**：它过了，再生成其余带场景的图；没过，先改所有剩余 prompt 的尺度句。

## 6. 各级别怎么拍

| 级别 | 好用的参照 | 最远退到 |
| --- | --- | --- |
| 掌心级 | 手指、耳垂、锁骨、手腕、首饰盘 | 上半身局部、桌面一角。不拍房间 |
| 手级 | 手、杯子、书、台面边缘 | 一张桌面、一格搁板 |
| 小臂级 | 手、椅背、门、壁炉台面、沙发一角 | 一面墙、一个壁炉、一个门口 |
| 躯干级 | 人的半身、沙发、床、门 | 房间一角 |
| 家具级 | 见 furniture-scale.md | 整个房间 |

掌心级和手级的产品，卖点里有「大小」时用构图 `C`（上身上手）或 `H`（尺度参照）来证明，不靠环境远景。
