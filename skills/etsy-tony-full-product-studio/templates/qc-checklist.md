# QC Checklist

## Order and Product

- [ ] SKU and option codes match order.
- [ ] Product/material/finish/size match card.
- [ ] Artwork/file version is released.
- [ ] Personalization spelling, date, case, punctuation, and layout match proof/order.
- [ ] Orientation, placement, scale, and functional clearance pass.

## Process Checks

Select applicable Laser, Embroidery, Printing/Transfer, Acrylic/UV, Wood/Cutting, Finishing, Assembly, and Packaging checks from references/quality-control-framework.md.

| Check | Acceptance Basis | Pass/Fail | Defect | Rework | Reviewer |
|---|---|---|---|---|---|

## Final

- [ ] Surface clean and damage-free.
- [ ] Assembly and functional use pass.
- [ ] Included parts and exclusions are correct.
- [ ] Packaging protects the vulnerable zones.
- [ ] Evidence photos saved.
- [ ] Reworked items received second inspection.

Disposition: Pass / Rework / Hold / Reject.
