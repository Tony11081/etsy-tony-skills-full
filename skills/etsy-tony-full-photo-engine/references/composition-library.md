# 构图库：卖点怎么变成画面

写 `art_direction` 时读取，排在 [art-direction.md](art-direction.md) 第 1、2 节之后、[scene-library.md](scene-library.md) 之前或同时。scene-library 管「在哪拍、什么光、什么颜色」，本文件管「拍成什么样的画面」。只读第一、二节和对得上的那一个产品家族。

一套图看着单调，原因几乎总是同一个：每张都是「产品居中摆着」，只换了背景。解决办法不是多想几个背景，而是先把卖点列出来，再让每个卖点用最适合它的构图去证明。卖点不同，构图自然不同。

## 一、先列卖点

写 `selling_points`，三到五条，按重要程度排序。每条写三样：

| 项 | 内容 |
| --- | --- |
| `point` | 卖点一句话。只写参考图和已确认事实撑得住的，不编工艺、材质、功能 |
| `proof` | 买家要亲眼看到什么才信。「名字是绣上去的」→ 看得清线迹的近景；「够装礼物」→ 真的装着礼物 |
| `compositions` | 用第二节哪几种构图来证明，至少两种 |

卖点从五个方向找，每个方向都过一遍，没有就跳过：

1. **定制**：名字、日期、首字母、照片、字体和颜色可选。
2. **做工与材质**：面料、木纹、缝线、刻痕、镶嵌、手工痕迹。
3. **功能与使用**：装得下什么、怎么挂怎么戴怎么开合、日常怎么用。
4. **规格**：尺寸、容量、成套件数、可选款式。
5. **场合与情感**：送谁、什么节日、纪念什么、放在家里哪个位置。

排序的依据：买家搜索时会打出来的词排最前（personalized、velvet、set of 4）；同类商品没有、这件有的排其次；其余在后。排第一的卖点决定主图。

## 二、十三种构图

每张图在计划里标一个 `composition` 代号，并写它证明哪条卖点。

| 代号 | 构图 | 画面 | 最擅长证明 |
| --- | --- | --- | --- |
| `A` | 单品主角 | 一件产品完整入画，招牌特征朝镜头 | 这是什么、长什么样 |
| `B` | 成组成排 | 多件按关系排开：一家人、一整套、一个系列 | 成套、家庭、数量 |
| `C` | 上身上手 | 佩戴、穿着、手持，只拍人体局部 | 上身效果、真实大小 |
| `D` | 使用进行时 | 正在被用的一瞬间：倒、切、塞礼物、扣搭扣 | 功能、日常、情感时刻 |
| `E` | 俯拍平铺 | 正上方，产品和几件相关物排开 | 搭配、场合、包含什么 |
| `F` | 招牌近景 | 贴近头号卖点：名字、刻字、镶嵌 | 定制内容、精细度 |
| `G` | 质感侧光 | 低角度侧光下的材质、缝线、边缘 | 做工、材质 |
| `H` | 尺度参照 | 和手、家具、门、常见物在一起 | 大小 |
| `I` | 环境远景 | 退后一步，看它在房间里的位置 | 家里放哪、整体气质 |
| `J` | 礼物时刻 | 包装好、正在拆、递出去、在礼物堆里 | 送礼 |
| `K` | 框景与前景 | 透过门框、枝叶、虚化前景看到产品 | 氛围、被「发现」的感觉 |
| `L` | 状态与角度 | 开与合、正与反、空与满、侧面背面 | 结构、容量、背面做工 |
| `M` | 选项陈列 | 颜色、款式、字体排开 | 可选项 |

**整套的多样性规则**（15 张为例，其他张数按比例）：

- 至少用到 7 种构图；同一种最多 3 张；相邻两张不同种。
- 排前三的卖点，每条至少有两张不同构图的图在证明。
- 主图用最能同时交代「是什么」和「头号卖点」的那一种：多数产品是 `A`，成套卖的是 `B`，戴在身上的是 `C`。
- 景别也要散开：远（`I`、`K`）、中（`A`、`B`、`D`、`E`）、近（`C`、`H`）、特写（`F`、`G`）四档都要有，任何一档不超过一半。
- 同一种构图出现第二次时，机位高度、产品朝向、时刻至少换两样。
- `M` 和带尺寸数字的 `H` 用确定性拼图或叠加完成，不让生图模型画文字和数字。
- 带环境的构图（`H`、`I`、`K`，以及有家具、门、壁炉入画的 `A`、`B`、`D`）最容易把产品画大。按 [scale-realism.md](scale-realism.md) 写尺度句；`I`、`K` 先算产品该占画面多少，掌心级和手级的产品不拍房间远景，最远退到一张桌面。
- 人体只在类目允许、且人物预算内出现；`C`、`D` 用不了人时，改用隐含的使用痕迹（搭着的围巾、拉开一半的抽屉）。

出现下面任一种，构图计划重做：远景里产品为了醒目被放大；一半以上的图是 `A`；主图证明的不是头号卖点；有卖点没有任何一张图在证明；两张图只差背景。

## 三、各品类的卖点和构图菜单

每条给出常见卖点和一份构图菜单。菜单是候选，不是清单：按当前产品的 `selling_points` 挑，产品没有的卖点对应的构图不要硬拍。

### 节日袜与节日挂饰

**常见卖点**：名字定制；一家人成套、多款可选；面料质感（丝绒、毛口、流苏）；装得下礼物；节日气氛。

- `B` 一家人一排：壁炉台或楼梯扶手上三到五只，名字各不相同、全部朝镜头 → 成套、定制
- `A` 单只主角：正面完整，名字在画面上三分之一 → 款式、定制
- `F` 袜口名字近景 → 名字做得好不好
- `G` 侧光扫过绒面、流苏、绳边 → 面料
- `D` 往袜子里塞礼物的手，或踮脚够袜子的小手 → 装得下、节日那一刻
- `L` 空的和装满的并排；背面 → 容量、背面做工
- `H` 挂在门把或椅背上，旁边有成人的手臂 → 尺寸
- `J` 圣诞早晨的树下，袜子鼓鼓的，旁边是拆开的包装纸 → 情感
- `K` 透过前景虚化的树枝和灯串，看到壁炉上的袜子 → 气氛
- `E` 平铺：袜子、包装纸、剪刀、丝带，正在准备礼物 → 送礼
- `M` 所有款式或颜色排开 → 选项

### 个性化首饰

**常见卖点**：名字、首字母、生辰石定制；金属材质；戴上的效果和大小；礼盒；做工精细。

- `C` 锁骨、耳、手上的佩戴近景 → 上身效果
- `A` 石面或亚麻上的单件，45° → 款式
- `F` 刻字或镶嵌微距 → 定制、做工
- `H` 戴在手上和指尖对比；项链在身上垂到哪里 → 大小、链长
- `L` 搭扣、背面、侧面厚度 → 结构
- `J` 礼盒刚打开，旁边一张手写卡 → 送礼
- `B` 叠戴，或项链加耳环成套 → 搭配
- `D` 正在扣搭扣，或拨开头发露出耳环 → 日常
- `E` 梳妆台平铺：首饰、香水、丝巾 → 场合
- `M` 金、银、玫瑰金并排；生辰石排开 → 选项

### 婚礼用品

**常见卖点**：名字和日期刻字；婚礼当天上镜；成套；婚后留作纪念；尺寸。

- `D` 两只手一起握刀切蛋糕 → 当天那一刻
- `A` 刀铲在蛋糕旁，45°，刻字朝镜头 → 款式、定制
- `F` 刻字近景 → 定制
- `B` 整套（刀、铲、盒），或一桌桌号排开 → 成套
- `I` 整张长桌的远景，产品在其中 → 上镜
- `E` 备婚平铺：请柬、丝带、戒指和产品 → 场合
- `H` 桌号旁的酒杯和餐盘 → 大小
- `J` 礼盒里的套装 → 送新人
- `K` 透过前景花艺看到主桌 → 气氛
- `I` 婚后摆在书架上，旁边是婚礼照片的相框 → 纪念

### 婴童与育儿

**常见卖点**：名字定制；柔软、安全的材质；尺寸；纪念意义；送礼体面。

- `A` 搭在小床栏杆上的毯子，或墙上的名字牌 → 款式、定制
- `E` 俯拍：毯子铺开，上面是木玩具和小鞋 → 场合
- `C` 裹着宝宝的背影，小手抓着毯角 → 使用
- `F` 名字刺绣近景 → 定制
- `G` 侧光下柔软的褶皱和织纹 → 材质
- `H` 铺在婴儿床里，或搭在摇椅扶手上 → 大小
- `J` 迎婴礼的礼盒 → 送礼
- `I` 婴儿房一角 → 家里放哪
- `L` 折好的和展开的；正反面 → 结构
- `M` 颜色叠成一摞 → 选项

### 木制与雕刻礼品

**常见卖点**：刻字定制；实木纹理；真的能用；尺寸和厚度；乔迁、新婚送礼。

- `A` 斜靠在墙上，刻字正对镜头 → 款式、定制
- `D` 正在切面包或摆奶酪，刻字不被盖住 → 能用
- `F` 侧光下刻痕的深度 → 定制、做工
- `G` 木纹和倒角的边缘 → 材质
- `L` 侧面厚度、背面、挂孔 → 结构
- `H` 手拿着，或和一条面包、一把刀在一起 → 大小
- `E` 俯拍：产品在中间，食材围一圈 → 场合
- `I` 厨房台面的远景 → 家里放哪
- `J` 系着丝带，旁边一张乔迁卡 → 送礼
- `B` 大中小号一组，或一摞杯垫 → 成套
- `M` 木种、字体排开 → 选项

### 家居装饰与墙面艺术

**常见卖点**：画面本身；尺寸可选；和家里搭；印刷、装裱质量；定制。

- `I` 沙发或床头上方的正面远景，比例正确 → 和家里搭、大小
- `A` 正对画面，完整 → 画面
- `F` 画面局部：笔触、印刷细节 → 质量
- `G` 斜侧面看纸的肌理、画框厚度和转角 → 装裱
- `H` 手持，或人站在旁边的背影 → 大小
- `B` 两三幅组成的组合墙 → 成套
- `L` 有框和无框；背面的挂件 → 结构
- `D` 手正在把画挂上墙 → 使用
- `K` 透过门框看到房间里的画 → 气氛
- `I` 换一个房间：客厅、卧室、玄关各一张 → 百搭
- `M` 尺寸对比示意 → 选项

### 厨房与餐桌

**常见卖点**：图案或定制；容量和尺寸；材质；天天用；送礼。

- `C` 双手捧着，杯里有内容物 → 使用、大小
- `A` 桌上单只，图案正对 → 款式
- `L` 把手一侧、背面图案、杯底、杯内 → 结构
- `D` 倒咖啡的一瞬 → 日常
- `E` 早餐俯拍 → 场合
- `H` 握在手里，或和手机、书在一起 → 大小
- `B` 一对，或一套四只 → 成套
- `G` 釉面的光泽，布料的织纹 → 材质
- `I` 厨房开放架上 → 家里放哪
- `J` 礼盒和丝带 → 送礼
- `M` 颜色排开 → 选项

### 服装与刺绣

**常见卖点**：图案或刺绣定制；版型和上身效果；面料；尺码；送礼。

- `C` 穿着的半身，颈部以下，图案正对 → 上身效果
- `C` 背影或侧身 → 版型
- `E` 平铺搭配：牛仔裤、鞋、包 → 怎么搭
- `F` 刺绣或印花近景 → 定制、做工
- `G` 侧光下的面料、罗纹、走线 → 材质
- `A` 木衣架挂在白墙前 → 款式
- `L` 叠成一摞；袖口、下摆、内标 → 细节
- `D` 生活里的动作：拉帽子、插兜、抱着咖啡 → 日常
- `B` 情侣、亲子、闺蜜同款 → 成套
- `J` 礼盒里垫着薄纸 → 送礼
- `M` 颜色叠放；尺码表 → 选项

### 包袋与皮具

**常见卖点**：皮质；压印定制；容量和卡位；缝线和油边；送礼。

- `A` 桌面单件，45° → 款式
- `L` 打开看内部：卡位、隔层、装满的样子 → 容量
- `C` 手拿着、从口袋里取出、背在肩上 → 使用、大小
- `F` 压印刻字近景 → 定制
- `G` 侧光下的粒面、缝线、油边 → 做工
- `H` 和手机、银行卡、手在一起 → 大小
- `E` 随身物平铺 → 场合
- `D` 正在放卡或拉拉链 → 日常
- `B` 钱包、卡包、钥匙扣一套 → 成套
- `J` 礼盒 → 送礼
- `M` 皮色排开 → 选项

### 宠物用品与宠物纪念

**常见卖点**：名字定制；合身；结实舒适；上镜；纪念意义。

- `C` 戴在宠物颈上的近景，毛发真实 → 上身效果
- `A` 单件平放或挂在挂钩上 → 款式
- `F` 名牌上的刻字 → 定制
- `G` 织带和扣具 → 做工
- `H` 卷尺旁，或不同体型对比 → 尺码
- `D` 主人的手正在给它系上 → 日常
- `I` 门口：挂钩上的牵引绳、项圈、鞋 → 家里放哪
- `E` 遛狗用品平铺 → 场合
- `M` 颜色排开 → 选项
- 纪念类：`A` 窗台上的相框、项圈和纪念牌；`C` 双手捧着；`F` 刻字；`I` 书架上的位置。留白多，光安静。

### 文具纸品与请柬

**常见卖点**：设计和文字定制；纸质和工艺；成套；尺寸。

- `E` 整套平铺 → 包含什么
- `A` 单张主卡 → 设计
- `F` 侧光下的烫金或凸版 → 工艺
- `G` 侧面一摞，看厚度和毛边 → 纸质
- `C` 手拿着 → 大小
- `D` 正在装信封、盖火漆 → 使用
- `B` 主卡、回执、信封展开 → 成套
- `K` 前景是虚化的花材 → 气氛
- `M` 配色、字体排开 → 选项

### 蜡烛、香氛与身体护理

**常见卖点**：香味；容器和标签；点燃的气氛；尺寸和时长；送礼。

- `A` 单只，标签正对 → 款式
- `D` 点燃的状态，火苗小，周围保持中性 → 气氛
- `E` 俯拍：产品和香味原料（柑橘、雪松、薰衣草）→ 香味
- `F` 标签和蜡面的质地 → 做工
- `H` 手拿着 → 大小
- `I` 浴缸边、床头、茶几 → 家里放哪
- `B` 三只一套，或一个系列 → 成套
- `L` 开盖和盖着 → 结构
- `J` 礼盒 → 送礼
- `M` 香型排开 → 选项

### 家具与大件

尺度和人物按 15 图 Skill 的 furniture-scale.md。构图菜单：`I` 房间远景；`A` 正面；`L` 侧面、背面、开合、收纳状态；`F` 榫卯、拉手；`G` 材质；`H` 人站或坐在旁边的背影；`D` 拉开抽屉、放上东西。

### 数字产品与 POD 底品

`A` 在真实载体上的正面；`I` 使用环境；`F` 细节；`E` 打印出来的平铺；`H` 手拿着打印件；`B` 包含内容一览；`M` 尺寸、版本。`B` 和 `M` 用确定性拼图。

### 找不到对应品类

按第一节把五个方向过一遍，列出卖点，再用第二节的表逐条配构图，同样受多样性规则约束。
